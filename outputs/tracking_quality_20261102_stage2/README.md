## 変更

1. 元の同じ人物IDが連続し、移動予測との距離が箱高さの0.40未満の場合、
   対象外人物の服との比較だけで割り当てを拒否しない。最大2フレームの間隔まで。
   他の位置・服・箱サイズの判定は維持。新IDや長い欠落からの復帰には従来の拒否規則を使う。
2. 奥側領域（元画像のx=0.18〜0.82、y=0.43〜0.68）を切り出し、
   同じ既存YOLO11m、imgsz1280、conf0.25で追加検出。
   元枠と重なる候補、切り出し端で切れた枠などは追加しない。
   追加枠に別系列のIDを付け、従来と同じ4人同時割り当てへ渡す。
3. 遮蔽中に箱が徐々に縮んで頭だけの枠へ移る問題を防ぐため、
   開始時の箱高さの半分未満の枠を拒否する。
   この簡易規則は全身や接地を保証しない。深い屈伸で正しい枠を拒否する可能性も残る。

044の手前後衛は、元のID1の検出枠があるのに服の拒否規則で70フレーム欠落していた。

056の手前後衛の46フレーム欠落は画面外への移動を含むため、そのまま保持。
補間・外挿で見かけの4人追跡を作ってはいない。
