# ラリー全体の経路によるF1/F2対応の再検討（2026-11-02）

ユーザーの「何とか解決できないか」に対し、048の同一ユニフォームの2人を
ラリー全体の軌跡から同時に追う方式を試作した。従来の候補・失敗例・人手ラベルは保持。
F1/F2のラベルを特定フレームから手動反転する処理ではない。

## 方法

同じ検出枠を使い、奥側2人の候補の組み合わせを同時に探索する。
1フレームごとの選択で確定せず、48個まで異なる軌跡仮説を保持するビーム探索を使う。
位置・速度の連続性、箱サイズ、服の特徴、対象外人物との違い、2人で同じ枠を使わない条件を評価。
全区間を処理した後に経路をたどり直し、後続フレームの情報も使って前の対応を決める。
ビーム探索は近似であり、全候補の大域最適解を保証しない。

欠落中には内部の位置予測を使うが、CSVや映像へ予測座標・補間位置は出さない。
出力の全座標は当該フレームの実検出枠に対応する。
元の検出IDは弱い手がかりとして扱い、人物IDと同一視しない。
手前2人は第4段階の候補を再利用。今回の改善対象は奥側2人だけ。

## 確認できたこと

- 同じ服の2人が交差し、検出IDが途中で変わり、交差点で1人しか検出されない模擬例で、
  移動の連続性に沿う人物対応を維持するテストが通った。
- 実映像048について、旧再取得版とは異なる人物対応の経路が出た。
- 順方向の経路から選んだ終盤F126741の2人を起点として、同じ探索を逆向きにも実行。
  開始時の元ID5→F1、元ID2→F2へ戻り、両方向で観測された対応枠1334組は全てIoU>=0.5で一致した。

逆方向の起点は順方向の候補から作ったもので、独立した人手正解ではない。
方向の一貫性が高くても、両方向が同じ誤りをする可能性は残る。
1334組は独立した本人確認件数ではなく、連続フレームの箱の比較数である。

旧版のユーザー指摘済みの入れ替わりを解決したかは、新しい映像で本人対応を確認して判断する。
現時点の出力は `offline_path_candidate_requires_review`。一般化したID精度や解決済みとは扱わない。
048を改善に使ったため、未使用評価の成績ではない。

検出枠との座標一致と一対一割り当ても検査済み。
