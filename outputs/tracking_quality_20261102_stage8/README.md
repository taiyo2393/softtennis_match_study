# 003・007・025への固定設定の適用（2026-11-02）

005の第7段階動画について、ユーザーからF1/F2が入れ替わらず同じ選手を追えているとの
確認を得た。記録は第7段階 `players_005_global/human_video_review.json`。
これにより002・005は提示動画の本人対応を確認済み。048も確認済みの経路と第7段階の出力が同一。
各確認を独立した全フレームID正解や別区間の承認には拡張しない。

## 固定した条件

第7段階のコードと設定を変更せず、003・007・025に適用した。
対象区間・最大600ソースフレーム・ソースハッシュは推論前に `transfer_protocol.json`へ保存。
各出力のコードハッシュと設定が、確認済み第7段階の実行と完全一致することを検査した。
3区間はいずれも同じ試合内で、過去に単一画像等の確認がある。未使用試合での評価ではない。
既存の主カメラ候補区間内に制限し、厳密に人手確定したラリー全長とは呼ばない。

別の軌跡へつなぐ時の本人対応までは保証できず、025で不一致が残った。

## 003の手前側の欠落

N1（区間内の仮ラベル、前衛の役割とは限らない）はサーブで腕を上げた状態から初期化される。
初期化フレームの箱高さは約667px。欠落開始F4360でも元ID2の検出は存在し、高さ約293px。
「初期の箱高さの半分未満を断片として拒否する」手前側の処理が通常姿勢にも適用されている。
欠落はF4360〜4615の256フレーム。欠落開始以降は復帰制約も影響し得るため、全欠落を
検出器の見逃しとは扱わない。
奥側の新しい全区間探索とは別に、手前側でサーブ姿勢から通常姿勢への変化を扱う必要がある。
