ラリー区切り：そのフレームから番号が1増えます。同じフレームでもう一度 R を押すと削除できます。

キー操作
  • Space 再生・一時停止
  • ← / → 1フレーム移動（Shift で6フレーム）
  • J / K 前・次の候補で停止（候補ありのみ）
  • N 手前 ／ F 奥の打球。±10F以内の最も近いラベルは現在位置に移動・側を更新
  • S 現在位置±10Fのラベルのサーブを切替。先に N / F で打球を付ける
  • Backspace / Delete ±10Fの最も近いラベルを削除
  • R 現在フレームに「ここから新しいラリー」の印。同じフレームで再度押すと削除
  • E 現在フレームが属するラリーの最後の打球の結果を unknown → winner → out → net → unknown と切替
  • Enter この点を完了。入力欄・選択欄・ボタンにフォーカス中はショートカット無効
