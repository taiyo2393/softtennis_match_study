## 手順と所要時間の見込み

1. 作業者名・点を選び、「候補なし」で開始します。既存の試行があれば同じ条件の最新試行を再開します。
2. 最初に全体を再生して、レット・フォルト後のやり直しなど複数の流れがあるか確認します。最初の再生・移動・ラベル操作で計時が始まります。
3. 打球の前後をコマ送りで確認し、ラケットにボールが当たったフレームで N（手前）または F（奥）を押します。サーブはその後 S。画面にも同じ説明を常時表示します。
4. 次の流れが始まる位置に移動し、R（ここから新しいラリー）を置きます。旧A/Bの区切りを再利用せず、本人が映像で決めます。
5. 各ラリーの最後の打球の結果を E で指定します。クリップの最後まで見て、打球の抜け・余計な打球・区切り・サーブ・結果を確認します。判別できない結果は `unknown` のままにします。
6. Enter または「この点を完了」で、その点の全ラリーをまとめて確定します。完了後は編集できません。修正が必要なら「同条件で新しい試行」で空の記録から始めます。
7. 「CSV を書き出す」でラベル・作業記録の**2ファイル**を保存し、両方のダウンロードを確認します。ブラウザが複数ダウンロードの許可を求めた場合は、このローカルページを許可します。「全記録の JSON を保存」でもバックアップしてください。

映像は計 **77.83秒**。初回の全体確認、打球前後の反復・コマ送り、最終確認を含め、**5点で20〜40分程度を仮の予定**とします。実測値ではなく、判別しにくい打球が多ければ超過します。最初の1点の実測を使い、残りの見込みを見直してください。旧ラベルの件数を作業量の根拠にしません。

## 操作とラリー区切り

画面の説明：**ラケットにボールが当たったフレームで、手前なら N、奥なら F。サーブは付けたあと S。最後の打球の結果は E。**

| キー | 操作 |
|---|---|
| Space | 音声付き再生・停止 |
| ← / → | 1F移動して停止。Shift併用で6F |
| J / K | 前・次の音候補へ移動。「候補なし」では無効 |
| N / F | 現在フレームに手前 / 奥の打球。同じラリー内の±10Fの最も近い打球があれば位置・側を更新 |
| S | 同じラリー内の±10Fの最も近い打球のサーブを切替。先に N/F を押す |
| Backspace / Delete | 同じラリー内の±10Fの最も近い打球を削除。Rの印は削除しない |
| R | 現在フレームにラリー区切りを追加。同じフレームで再度押すと削除 |
| E | **現在フレームが属するラリー**の最後の打球の結果を `unknown → winner → out → net → unknown` と切替 |
| Enter | この点の全ラリーを完了。空ラベルでの完了は防止 |

`rally_no` は1から始まり、Rの**置かれたフレームを含めて**以後の番号が1増えます。例えばRをF23000に置くと、F22999までは1、F23000からは2です。印を後から追加・削除しても、時間順に番号を振り直します。同じフレームに印は1つだけです。第1ラリーの開始位置にRを置く必要はありません。

Rはタイムラインと区切り一覧に表示します。修正時は一覧の「このFへ」で移動し、表示確定後にRを押して削除してから正しい位置に置き直します。区切りの追加・削除で各ラリーの最後の打球が変わった場合は結果を再確認してください。各ラリーの途中の打球は `continue`、最後の打球は4択です。打球のないラリーでEを押しても他のラリーの結果を変更しません。Rは境界の印であり、打球としては数えません。

手前は青い●、奥は橙の◆、サーブは★です。タイムラインやラベル一覧から移動できます。同距離のラベルは早いフレームを優先します。同じラリー内の±10Fに別々の打球を作れない操作仕様は従来どおりです。入力欄・選択欄・ボタンにフォーカス中はショートカットが無効なので、映像かタイムラインをクリックしてください。シーク中のラベル入力は防止します。

フレーム番号は元動画の0始まりです。1Fは1001/60000秒。`requestVideoFrameCallback` 対応時は提示された映像の `mediaTime` から、未対応時は `currentTime` から表示フレームを計算します。コマ送りは整数フレームの時刻に1マイクロ秒を加えて丸め誤差を避けます。

## 保存とCSV

保存キーを **`match2-human-relabel-scenes-v2`**、保存形式をversion 2に変更しました。旧キー `match2-human-label-study-v1` の記録は読み込み・移行しません。新しい試行は打球もRの印も空で始まります。

同じ名前・点・条件・候補版の最新試行を開きます。条件を切り替えると別の空の試行になり、ラベル・区切りは引き継ぎません。「保存済みの試行」から過去の記録を開けます。名前と候補版は作業中に固定します。Web Locks対応時は同時作業タブを1つに制限し、未対応時もタブ間通知・保存変更通知で競合を検出します。

各操作・切替・完了時と作業中は約1秒ごとにブラウザの `localStorage` へ保存します。保存できない場合は通知し、画面内で作業を継続します。壊れた保存データは自動上書きしません。ブラウザデータを削除すると記録が失われるため、CSV/JSONも保存してください。強制終了では最後の保存から約1秒分の情報が失われる可能性があります。

ラベルCSVは**従来の列順を保ち、末尾に `rally_no` を追加**します。

```text
point,rally,frame,side,is_serve,outcome,trial_id,participant,condition,candidate_version,status,rally_no
```

`rally=all` は点ごとに統合したクリップを示す固定値です。実際のラリー識別には `point` と `rally_no`、試行識別には `trial_id` を使ってください。旧A/Bとの対応は保証しません。`side=N/F`、`is_serve=true/false`。Rの位置そのものはJSONの各試行の `rally_breaks` と操作履歴に保存します。Rの印だけの行はラベルCSVに出しません。

作業記録CSVの列は変更しません。

```text
point,rally,condition,start,end,active_seconds,idle_seconds,n_actions_by_type,participant,trial_id,candidate_version,status,elapsed_seconds,away_seconds,playback_seconds,compared_at,reference_exposed_before_start
```

比較機能は廃止したため、互換用の `compared_at` は空、`reference_exposed_before_start` はfalseです。条件は `with_candidates` / `without_candidates`、候補なしは `candidate_version=none`。時刻はUTCのISO 8601（末尾Z、日本時間は+9時間）。CSVはUTF-8 BOM付きで、JSON文字列・改行・引用符をCSVとしてエスケープします。

両CSVは全試行を含み、未完了は `status=in_progress`、`end` 空欄です。計時前の空試行は出力しません。正解として採用する完了試行は `trial_id` を指定し、複数試行を混ぜないでください。

## 計時の定義

- `elapsed_seconds`：最初の対象操作から点の完了までの実時間。未完了は現在まで。
- `idle_seconds`：操作間隔が60秒以上なら、その間隔全体（最初の60秒も）を除外します。条件・点・試行の切替、非表示タブ、ページ終了中の時間は60秒未満でも除外し、重複区間は和集合にします。
- `active_seconds`：経過時間から無操作時間を引いた値。60秒閾値に到達すると表示値が減る場合があります。
- `away_seconds`：無操作時間の内数です。再加算しません。
- `playback_seconds`：再生中の実時間の累積。反復再生は加算し、シーク・停止・バッファ待ち・完了後の再生は含めません。速度は1倍固定です。
- 操作数：従来の再生・移動・N/F/S/削除/E等にRと区切り一覧からの移動を追加。空振りも `changed:false` として記録します。設定選択・保存・完了後の閲覧は含めません。

本人が映像を見て考えている時間も無操作になり得るため、`active_seconds` は認知的作業時間の直接測定ではありません。経過時間と併記します。今回は正解ラベルの作成が目的で、候補あり／なしの効果比較実験ではありません。区間は場面データから事前選択済みなので、試合全体からラリーを探す時間も含みません。
