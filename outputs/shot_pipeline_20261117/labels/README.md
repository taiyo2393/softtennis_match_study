# Claude の打球ラベル（match2 第7〜11点）：信頼できない

2026-11-17 に Claude が、6フレームおきのコマのシートから付けたラベル（91件）。**2026-11-18 に、打球の時刻と数が大きく誤っていることが分かった。正解として使わないこと。**

## 分かったこと（2026-11-18）

- 本人（ソフトテニス経験者）が動画で確かめたところ、第8点の p08_B_06（ラベル F25356、手前の打球）の本当の打球は **F25321** だった（35フレーム＝0.58秒のずれ）。F25321 は Claude のラベル #4（F25324）にあたる。#5（F25348）と #6（F25356）は、存在しない打球をはさみ込んだ可能性が高い。
- 同じ点の中の、隣り合うラベルの間隔（rally A を除く81組）を見ると：
  - 間隔の中央値は16フレーム（0.27秒）。
  - 46組が18フレーム（0.3秒）未満で、38組が14フレーム以下。
  - そのうち8組は、両方が「clear」のラベルだった。
- ソフトテニスで、相手の打球から次の打球まで0.3秒未満というのは、物理的にほぼありえない。ネット前の打ち合いでも、もっと長い。Claude が、振りや構えの動きを打球と見なし、手前と奥が交互になるように打球を足していったと考えられる。「clear」の判定も当てにならない。
