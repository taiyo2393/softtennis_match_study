## 追記（Claude、2026-11-18）：音は打球の約5フレーム後に一定して出る

本人の打球と、最も近い音 v1 の候補とのずれ（ラリーの範囲、32打球）は次のとおり。

- 26打球が +4〜+6 フレーム（音が後）。中央値は手前も奥も +5 フレーム（0.083秒）。
- 外れは6件（−6、−6、−4、−3、−1、+2、+8、+10 のうちの一部）。

手前と奥で同じずれなので、選手とマイクの距離による音の遅れではない。放送の音声と映像のずれ（一定）と考えられる。したがって、候補の時刻から5フレーム引けば、多くの打球で ±1〜2 フレームの精度で接触の瞬間が分かる見込みがある（未検証）。

まとめると：
- 音の候補は、打球の時刻の精度は高い。
- 数が多すぎる（1打球あたり約7件）ので、「どれが打球か」は人が選ぶ必要がある。
- 人が付ける作業では、「打球の近くの候補へ移動して、選ぶ」という操作にすれば、コマ送りの回数を減らせる可能性がある。本人の作業記録では、1コマ送りが5点で723回あった。
