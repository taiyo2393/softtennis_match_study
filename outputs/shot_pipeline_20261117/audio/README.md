## 検出法と探索

4次Butterworth帯域通過をsosfiltfiltでゼロ位相適用 → 2 ms平均二乗エネルギー（1 ms刻み）→ 自然対数（下限1e-12）→ 中央の局所中央値を減算 → scipy.signal.find_peaksの高さと最小間隔で検出。中央値窓は1 ms刻みで最近奇数へ切り上げるため、実際は301/501/1001サンプル。強さはこの対数差で、確率ではない。ステレオ差分とspectral fluxは今回の探索には含めない。

- 帯域Hz：1000–4000, 2000–6000, 3000–10000, 1000–10000, 4000–12000
- 局所中央値秒：(0.3, 0.5, 1.0)
- 高さ閾値：(0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 2.5, 3.0)
- 最小間隔秒：(0.06, 0.1, 0.15, 0.2)
- 合計480設定。全設定の探索用成績をparam_search.csvに保存。

**設定選択基準**：第7・8点を合算し、候補/秒が全ラベルの打球数/秒の2倍以下 （候補118件以下）の設定からclearの±6フレーム再現率が最大のものを選ぶ。同率なら候補数が少ないもの、さらに同率ならconfig_id昇順。±10・適合率・側別・評価用成績は選択に使わない。第7・8点だけを読み込んで探索し、selected_config.jsonを保存した後に第9〜11点を読み込む。評価結果を見た再探索・再調整は行わない。

選択：**cfg_427、4000–12000 Hz、中央値0.5秒、閾値1、最小間隔0.15秒**。

## 1対1対応と指標

各許容幅（±6、±10）で独立に、同じ点/rallyの候補と全ラベルの許容ペアを絶対フレーム差の近い順に並べる。両端が未使用のペアだけを採用する貪欲法。距離同率ではラベルF、候補F、label_id、candidate_id順。同じ対応結果をclear/allおよび手前N/奥Fで集計する。側ごとに対応をやり直さない。inferredも対応に参加するので、近接するclearとの競合は起こり得る。参考列 `recall_clear_separate_matching_f6/f10` はclearのみで別に1対1対応した感度分析であり、設定選択には使わない。

- recall_clear/all_f6/f10：対応した該当ラベル数÷該当ラベル総数。
- precision_proxy_f6/f10：全ラベルに対応した候補数÷候補総数。打球の全網羅が未確認なので**適合率の目安**。
- candidates_per_sec / labels_per_sec：合計件数÷合計区間秒。合計行は点ごとの率の単純平均ではない。
- delta_*：候補F−ラベルFの符号付きずれ。中央値・最小・最大、絶対値中央値を保存。空欄は対応/分母なし。
- review_coverage_plusminus10_frames：候補±10Fの窓の和集合が区間秒に占める割合。重複を除き端で切る。確認映像の理論的範囲であり、人の操作・修正時間や打球捕捉の保証ではない。

## 限界と研究上の判定

1. Claudeの1回の映像ラベルであり、clearにも±6F程度の不確かさがある。この目安自体も独立検証していない。±6Fは約0.100秒、±10Fは約0.167秒。真の接触時刻に対する検出誤差とは区別する。
2. inferredは前後関係からの推定を含み、未ラベルの中間打球も既存noteにある。ラベルのない候補を誤検出とは断定できず、対応した候補もバウンド・足音・声などとの偶然一致があり得る。本実験は音イベントの種類を独立に判別していない。
3. 同一試合の連続した5点だけで、評価用clearは18件（手前5・奥13）。側別差の原因を音量と断定できない。第11点はエンド交代もある。480設定からの選択は探索側を楽観的にする。評価側は固定しているが、別試合・別収録への一般化は未検証。
4. 解析区間はラベルから与えられた短い区間である。試合全編での候補密度や自動ラリー切り出しは評価していない。探索用の候補密度上限は評価用で満たされる保証がない。mono化でステレオの空間情報を捨てている。
5. 音の伝搬・放送音声の遅延を補正しない。sosfiltfiltと中央中央値は未来の音声も使うためオフライン処理。貪欲対応は最大対応数を保証せず、密集した候補の偶然一致を差し引く指標でもない。
6. 卒論の中心的な有効性を主張するには、独立に確認した打球ラベルを用い、全区間確認と候補前後確認の比較で、最終データの欠落/誤りと人の確認・修正時間を測る必要がある。今回の一致率と理論窓割合だけから作業時間短縮や戦術データの正しさは主張できない。

実行所要時間（この実行環境、抽出・探索・評価・図作成を含む）：25.19秒。

### 特徴量と固定した規則

すべて48 kHz mono、2 ms平均二乗・1 ms刻み。時刻補正なし。帯域は4次Butterworthのゼロ位相処理。
- `half_width_ms`：高域の線形エネルギーから501 ms局所中央値を引いたピークの半値幅。交点を補間し、左右各100 msで打ち切る。打切りは`width_censored`に記録。
- `low_rise_ln` / `high_rise_ln`：0.5–2 / 4–12 kHzの対数エネルギーと501 ms局所中央値との差。低域は候補の±4 ms内の最大、高域は候補時刻。両方の小さい値を`paired_rise_ln`にする。低域ピークのずれも±4/±20 ms内で保存する。
- `post50_drop_ln`：高域ピークエネルギー÷45–55 ms後の平均エネルギーの自然対数。大きいほど急減。
- `energy_concentration_20_100`：局所中央値より大きい高域エネルギーの±20 ms積算÷±100 ms積算。
- `spectral_flatness_100ms`：±100 msの短時間平均PSDについて0.5–12 kHzで幾何平均÷算術平均。調波音の参考特徴として保存するが、探索には使わない。

選択規則 **rule_0564**（以下の有効条件をすべて満たす）：

- 半値幅 ≤ **15 ms**
- 両帯域の立ち上がり（対数局所差の小さい方） ≥ **0.5**
- 50 ms後の低下（自然対数） ≥ **1**（後/ピーク ≤ 0.368）

第7・8点だけで探索。候補の教師値は、同じ点/rallyにclearまたはinferredのラベルが整数フレーム±10F以内に1件でもあれば正例（候補間のラベル共有を許す）。評価用の1対1対応とは分ける。

探索格子（`None`は条件なし）：`{"max_width_ms": [null, 6.0, 10.0, 15.0, 25.0, 40.0, 80.0], "min_paired_rise_ln": [null, 0.0, 0.5, 1.0, 1.5, 2.0, 3.0], "min_post50_drop_ln": [null, 0.0, 0.5, 1.0, 2.0, 3.0], "min_concentration": [null, 0.3, 0.5, 0.7]}`。有効条件は最大3つ、計636規則。前回の探索側±10F対応数の90%以上（clear ≥ 35件、全 ≥ 46件）を保つ規則から、主指標の窓合計割合最小を選ぶ。同率は候補教師値に対するF1最大→条件数最小→規則ID順。この90%制約は探索時の設計値で、評価側の保証ではない。教師値は同じラベル近傍の複数候補も正例にするため、F1を主目的にすると重複候補を残しやすい。
