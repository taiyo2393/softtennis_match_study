自動v1・自動v2・Claudeの判定を表示し、ソフトテニス経験者本人が正誤を確認する画面です。分類を一から入力する方式から変更しました。外部ライブラリ・CDN・追加パッケージは使用しません。ブラウザでの実画面確認はClaudeが担当します。

`file://` では開かず、HTTPで使用します。動画は既存の `setVideoSource` と同じ `fetch → Blob → URL.createObjectURL` で読み込むため、Range非対応のPythonサーバーでもシークできます。生成時の実動画検証には既存の `ffprobe` を使います。サーバー終了は `Ctrl+C`。

## 確認の手順

1. 名前を入力し、手前N／奥Fと前衛の枠を確認して「前衛の選択」を回答します。各予測カードにも対象slotを表示します。v1／Claudeとv2の対象が異なる場合や未確定の場合は警告します。
2. 前後の打球を含む動画を見て、ラベルの相手の打球が「正しい／ずれている／分からない」か選びます。「ずれている」はコマ送りで合わせ、「今のフレームを相手の打球にする」または **T** で記録します。元の打球ラベルは保持します。
3. 自動v1・自動v2（足首）・Claude（参照がある20件のみ）のそれぞれで、**動きの有無・向き（3方向）・単／複**について、横並びの「正しい／違う／分からない」を押します。「動きなし」で向き・単複が「—」なら、その項目がないことの正誤を確認します。Claudeの未記入項目は推測せず「分からない」にできます。
4. いずれかが「違う」、または複数の「正しい」が矛盾すると、**正しい答え**の欄が出ます。なし／単／複／判定できない、向き、フェイントを入力します。全部が正しく矛盾しなければ追加入力は不要です。「正しい答えを自分で補う」でも入力できます。
5. 自信（高・中・低）と必要ならメモを入力し「次へ」。必須の確認漏れ、打球修正漏れ、修正答えの不足は通知します。最後は「完了する」、続いてCSVを書き出します。途中でも書出し可能です。

キー：`Space` 再生／停止、`←/→` 1コマ、`Shift+←/→` 6コマ、`T` 打球フレーム記録（ずれている選択時）、`Enter` 次へ。文字入力中は無効です。動画クリックでも再生／停止できます。

## 区間と表示

- 抽出はClaude参照の20件と、残りのv2主条件のIDを整列して `Random(1986).sample(...,10)` した10件。提示順は `Random(20261118).shuffle()`。元版と同じ30件・順序で、先頭は `p08_B_06` です。再生成時も既存data.jsonとの順序一致をassertします。
- 全自動判定は **W=0.4秒、D=0.3m**。v1（箱の下端）・v2（足首）・v2（箱、参考）を並べます。本人の「v2」の確認対象は足首版です。箱版は参考表示のみで独立の正誤欄は設けません。
- 前後の打球は同一点・同一ラリーの `labels/point_XX.csv` の打球順で取得。「前」は前衛側の最後の既知打球、「次」は直後の既知打球です。相手側のラベルが連続する `p08_B_18` では前衛側のF25458まで戻り、間の見えていない打球は補いません。開始は `min(前の打球−0.2秒, 相手の打球−1.0秒)`、終了は `max(相手の打球＋1.0秒, 次の打球＋0.2秒)`。隣がない場合は相手の打球±1.0秒。秒をfpsで最寄り整数フレームに換算し、クリップ範囲へ切り詰めます。
- タイムラインに前の打球・相手の打球ラベル・次の打球、分類の始点と＋0.4秒を表示。ラベルのconfidenceがinferredなら **推定** を表示します。修正すると修正打球の印を追加し、分類の始点・＋0.4秒の印を移動します。修正後のフレームをCSVに残し、分類・元の軌跡は再計算しません。表示範囲外の印は端へ表示し、正確なフレームは印のツールチップで確認できます。
- v1の軌跡は追跡CSVの `bottom_center_x/y`、v2はpose cacheの `kp_15/16` の中点です。動画・追跡・poseは1920×1080の画面座標です。描画はv2の元の `contact_frame..end_frame` のみ（最大0.4秒、次打球でcap）。1フレームごとの生座標の線と始点→終点の矢印を色分けし、表示切替できます。分類の最終方向は同じ位置から破線矢印で示します。全変位の矢印と最終方向は複モーションで異なり得ます。Claudeの3方向（紫）とv2箱の最終方向（灰）も対象位置から破線矢印で表示・切替できます。Claudeの横は左右の両矢印で、8方向を推測しません。
- **描画する足首は左右ともconf≥0.3の中点だけ**。片足のみ・欠測は描画せず、欠測をまたいだ経路線をつなぎません。始終点の矢印は取得できた最初・最後の点の変位で、欠測中の経路の推定ではありません。v2分類自体は片足だけやcache範囲外の箱fallbackも使用し、コート座標を平滑化しています。生座標の表示はその計算結果そのものではありません。
- 方向ボタンは画面の8矢印で固定し、内部の言葉を前衛の側に応じて変更します。手前N：↑前、→右。奥F：↓前、←右。小コート図も前衛の位置とネット方向を切り替えます。
- 向きは前衛から見た方向。複は最後の決定方向です。3方向は前・横・後ろ。手入力の斜め前は前、斜め後ろは後ろへ縮約します。自動の3方向は連続変位の45度境界なので8方向からの縮約と境界付近で異なり得ます。
- 定義の手がかり：単は一度まっすぐ移動、複は予備の後に決定の動き。誘い（フェイント）は斜め前の予備から逆の斜め前へ決める型。モーションの論文上の終点（ネット通過／本人の接触）を、この固定0.4秒の印で実測したわけではありません。

- 動画の下の「拡大（前衛の周り）」は、表示区間内の最初の追跡箱の中心・高さ3倍の正方形を固定し、640×640 canvasへ拡大します。再生・コマ送り・シークでも中心・倍率は追従しません。動画の各フレーム更新（requestVideoFrameCallback、非対応時はrequestAnimationFrame）に合わせて描き、v1橙・v2水色の生座標の軌跡、始終点の矢印、現在フレームの前衛枠を同じ座標変換で重ねます。線の太さ・矢印の先端・文字は可読性のため表示側の大きさを使います。既存のv1／v2／前衛の枠のチェックボックスと連動します。最終方向の破線・参考方向は元動画側に表示します。画像端の外側は黒地とし、箱の欠測フレームは枠を補間せず、区間全体で箱がなければ拡大できない旨を表示します。画面上方向は奥Fなら「後ろ」、手前Nなら「前」です。

## 保存・CSV

新しいlocalStorageキーは **`softtennis-motion-confirm-1986-v2`**（旧 `softtennis-motion-reference-1986-v1` は読込みません）。同じブラウザ・ホスト・ポートで再開してください。保存形式／dataset_id不一致時は上書きせず停止。保存失敗は表示し、別タブの更新検出時も上書きを停止します。1人1タブで使用し、終了前にCSVを保存してください。

出力名は **`motion_review.csv`**。BOM付きUTF-8、30行、引用符・カンマ・改行をCSV規則でエスケープします。列は以下です。

| 列 | 意味 |
|---|---|
| id, point | ID、点 |
| contact_frame, corrected_contact_frame | 元ラベルのフレーム、本人の修正フレーム（ずれている時のみ） |
| contact_judgment | 正しい／違う／分からない。UIの「ずれている」はCSVでは「違う」 |
| player_judgment | 前衛の枠：正しい／違う |
| v1_motion_judgment, v1_direction3_judgment, v1_complexity_judgment | v1の各項目：正しい／違う／分からない |
| v2_motion_judgment, v2_direction3_judgment, v2_complexity_judgment | v2足首の各項目 |
| claude_motion_judgment, claude_direction3_judgment, claude_complexity_judgment | Claudeの各項目。参照がない10件は空欄 |
| motion, single_compound | 本人の動き none／motion／unknown、単複 single／compound（該当しない時は空欄） |
| screen_direction, player_direction8, player_direction3 | 画面の方向、前衛の8方向、3方向 |
| feint | yes／no／unknown |
| answer_origin | accepted：正しいと確認した項目から採用、corrected：本人の修正入力 |
| confidence, note | high／medium／low、メモ |
| seconds, annotator, saved_at | 作業秒数、名前、ISO形式の保存時刻 |

8方向は `straight_front / right_front / right_lateral / right_back / straight_back / left_back / left_lateral / left_front`、3方向は `front / lateral / back` です。全部正しいなら確認した予測から本人の答えを作ります。複数の採用内容で動き・単複・3方向・8方向・フェイントが矛盾すれば修正入力を求めます。「分からない」しかない項目は空欄／unknownとし、他の予測で勝手に補いません。フェイント・8方向は全項目を正しいとした予測から採用し、未確定ならunknown／空欄です。

作業時間は項目を開くだけでは開始せず、再生・コマ送り・回答・表示切替など、その項目で最初の操作から計時します。未操作・累積0秒なら「作業時間 —（最初の操作から計時）」と表示します。再訪時は保存済みの秒数を保持し、次の操作まで加算しません。既存の保存済み秒数は過去の待機時間を分離できないため、そのまま引き継ぎます。項目ごとに蓄積し、**60秒以上の無操作区間は区間全体を除外**します。自動の動画フレーム更新や定期保存では操作時刻を更新しません。タブ非表示・移動後の別項目の作業時間は加算しません。長時間の無操作で観察した時間も除かれるため、実際の観察時間の厳密な測定ではありません。

`data.json` は `json.dumps(..., separators=(",", ":"))` で圧縮記述します。枠座標は0.1pxに丸めた配列、軌跡は必要な短区間のみ。生成時に30件・一意ID・20+10件・元順序・動画の実フレーム数／fps／寸法・全表示範囲のclip内包・256KiB未満をassertします。入力CSV／クリップメタデータのSHA-256も記録します。生成スクリプトの書込み先はこのフォルダのdata.jsonのみです。

## 集計と検証

```powershell
& .\study\.venv\Scripts\python.exe -X utf8 -B .\outputs\shot_pipeline_20261117\motion_ui\compare_motion_labels.py "C:\path\motion_review.csv"
```

- **本人の確認による正解率**：v1／v2／Claudeの項目別に `正しい / (正しい＋違う)`。分からない・未入力は分母から除き、件数も併記します。
- **本人回答との一致**：本人が枠を正しいとし、予測と同じslot／側の対象で、本人回答が確定した件。動きの有無を比較し、本人が動きありで方向・単複が入力されている件ではそれぞれも比較します。自動の棄却・なしは不一致、Claudeの項目未記入は分母外です。対象違い、本人不能・未確認、打球修正行などの監査件数を併記します。
- **打球のずれ**：「違う」の件数、修正済み／未入力、修正−元の符号付きフレーム差、絶対差の平均・中央値・最大を出します。元の自動分類を再計算していないので打球修正行も元の予測との比較になります。
- ダミーテストは方向変換16通り、採用と矛盾、必須項目、不能、打球修正、60秒の計時境界、CSVの引用符・カンマ・改行、実30件の範囲と容量を確認します。JS exporterで作ったダミー30行をPython loader→集計CLIまで通し、重複IDも検出します。ダミーは一時領域で削除され、実際の本人データは作りません。

**研究上の位置づけ**：予測を見た確認式なので独立した盲検の正解率ではありません。accepted回答と元予測の一致には循環性があります。Claude既確認20件は非無作為・開発に使用済みで、残り10件も同じ試合からの固定標本です。未知試合への汎化精度、独立した正解ラベル、因果的効果の検証には使えません。今回の成果は、本人が誤りと原因を確認・修正するための記録と集計です。
