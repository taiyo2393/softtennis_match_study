## 対象と再現性

- `net_motion/review_claude_v1.csv` の20件と、それ以外のv2主条件86打球の残り66件から10件を無作為抽出します。ID順に整列してから `random.Random(1986).sample()` を使用し、30件の提示順は `random.Random(20261118).shuffle()` で固定します。v2の変更例から選んだ追加10件とは別の標本です。
- v2 `motions.csv` の `W_sec=0.4, D_m=0.3, coordinate_method=ankle` を使います。自動分類は監査用に `data.json` に保持しますが、画面には表示しません。Claudeの目視有無・目視内容も画面には表示しません。データファイルを直接読んだ場合の情報遮蔽までは提供しません。
- 各件にはid・点・ラリー・接触フレーム・前衛slot/側・v2の終点フレーム・自動分類を保存します。追跡枠は同じslotの `player_court_proxies.csv` からフレーム単位で抽出します。欠測を補間せず、slot未確定（今回の標本では `p08_B_08`）も差し替えません。
- 再生成時は30件の一意性、20+10の内訳、全表示範囲がクリップ内にあることを **assert** します。`ffprobe` で実際のフレーム数・fps・寸法と `label_ui/data.json` の整合も検証します。範囲を黙って切り詰める処理はありません。
- 入力CSV・クリップメタデータ・追跡CSVのSHA-256を `data.json` に記録します。再実行時の出力は決定的です。更新するのはこのフォルダーの `data.json` だけです。

## 定義と入力

- **ポジショニング**：相手が打とうとするとき、前衛が一時的に静止すること。
- **モーション**：相手の打球に対し、そこから意図的に行う移動。終点は相手の打球のネット通過、または前衛自身の接触まで。
- **単**：一度、まっすぐ動く。**複**：予備の動きのあとに決め手の動き（2段・3段）。
- **誘い（フェイント）**：予備で斜め前に出て、逆の斜め前へ決める型。

表示範囲は接触の約0.5秒前〜0.8秒後（fpsから最寄りの整数フレーム）。タイムラインに接触時点と0.4秒後を表示します。v2の実際の終点は「次の接触」と「0.4秒後」の早い方で、`end_frame` に保持しています。**0.4秒後の印はネット通過の実測値ではありません。** 本人は論文の終点を映像で確認して判断します。必要な終点まで見えなければ「判定できない／見えない」とし、メモに残します。

1. 名前を入力します（初期値は空欄。空欄でも保存可能）。同一のブラウザ・URLで1人が1タブだけを使います。
2. 「手前 N／奥 F」の大きな表示と枠で対象を確認します。枠は対象の推定であり正解ではありません。対象が違う場合は「判定できない／前衛が違う」を使います。
3. 再生・停止・ループ・コマ送り・速度を使って確認し、モーションを選びます。方向は**画面上の向き**で選びます。複は最初の予備と最後の決定を入力し、3段の中間の動きはメモに記載します。
4. 誘い・自信を選び「次へ」。未入力の必須欄があればその場で通知します。「はい」は複の場合に選択可能です。動きなしなら「いいえ」、判断不能なら「分からない」などを本人が選びます。方向や誘いを自動で推測して埋めません。
5. 最終件は「完了する」。全件完了後に「CSV を書き出す」で `motion_labels.csv` を保存します。途中でも書き出せます。未入力は空欄のままで、30行を出力します。

キー：`Space` 再生／停止、`←/→` 1コマ、`Shift+←/→` 6コマ、`1/2/3` なし／単／複、`Enter` 次へ。文字入力・セレクトなどにフォーカスがある間はショートカットを抑制します。動画をクリックすると再生／停止できます。動画は `fetch → Blob → URL.createObjectURL` で再生するので、Range非対応の `python -m http.server` でもシークできます。ブラウザが対応していれば表示フレームコールバックに同期して枠を描画し、それ以外は再生時刻から算出します。

方向変換は、手前Nなら画面の上＝前・右＝本人の右、奥Fなら画面の下＝前・左＝本人の右。FはNの方向を180度回転します。例：Nの↗は右斜め前、Fの↗は左斜め後ろ。変換結果を入力欄のそばに表示します。

`player_dir8_*` は既存分類と同じ `straight_front / right_front / right_lateral / right_back / straight_back / left_back / left_lateral / left_front`。`player_dir3_final` は斜めを含め、前の3方向＝`front`、左右＝`lateral`、後ろの3方向＝`back` とします。自動分類の3方向は連続変位の45度境界であり、8方向選択からのこの縮約と境界付近で完全には対応しません。方向一致率にはこの符号化の違いが含まれるため、純粋な移動推定誤差とは解釈できません。

## 保存と時間

`localStorage` の専用キー `softtennis-motion-reference-1986-v1` に自動保存します。読み書きをtry/catchで処理し、失敗時は画面に表示します。保存形式が壊れている場合は上書きせず開始を停止します。別タブから保存が変わった場合も上書きを停止します。作業は同じブラウザ・同じホスト名・同じポートで再開してください。名前はこの標本全体に適用されます。複数人の独立評定や編集履歴管理を行うシステムではありません。

作業時間はその件の最初の操作から「次へ」まで。動画の再生・移動・方向・ラベル・名前・メモ操作が操作に当たります。**操作間隔が60秒以上なら、その無操作区間全体を除外**します（最初の60秒も含めません）。自動ループやマウス移動だけでは操作時刻を更新しません。画面上の途中経過は、60秒に到達するとその区間分が除かれます。前へ戻る・タブ非表示・ページを閉じると区間を中断し、再開後の最初の操作から再計時します。他の件の作業時間は加算しません。同じ件を編集・再確認するとそれまでの時間に加算されます。5秒ごとの保存も行いますが、保存自体は操作に数えません。

CSVはUTF-8 BOM・CRLF、引用符と改行をエスケープします。列順：

```text
id,point,contact_frame,front_side,motion,unknown_reason,screen_dir_final,screen_dir_prelim,player_dir8_final,player_dir3_final,player_dir8_prelim,feint,confidence,note,seconds,annotator,saved_at
```

`motion` は `none/single/compound/unknown`、理由は `not_visible/wrong_player/other`、画面方向は `up/up_right/right/down_right/down/down_left/left/up_left`、誘いは `yes/no/unknown`、自信は `high/medium/low`。`seconds` は累積作業秒、`saved_at` はその件の最後の操作・確定時刻（UTC ISO 8601）。選択が不要になった方向・理由は空欄です。メモは自由記述です。

比較結果は標準出力のみ。ダミーCSV・比較結果はリポジトリに保存しません。v1・v2箱・v2足首はすべてW=0.4秒・D=0.3mを使い、Claudeの目視20件とも比べます。

- **有無**：本人の入力済み・判定可能な件を分母にし、自動の判定不能は不一致。本人の `unknown` と空欄は除外します。
- **3方向**：双方が動きあり、本人の方向が記入済みの件を分母にします。複の自動方向は `final_direction3`。自動の方向欠損は不一致です。
- **単・複**：本人が単／複を付けた件を分母にします。自動の「なし」・判定不能も不一致に含めます。Claudeが動きありだけを記入して単・複を未記入なら、この項目から除外します。
- v1やClaudeとv2で前衛slot/側が変わった件、slot未確定の件は同じ人の動きとして比較できないため除外し、別の件数表に表示します。Claudeの `wrong_player` や空欄も新しい選手のラベルへ読み替えません。
- 途中保存CSVも読めます。主評価は全30件を確認して書き出したCSVを使用し、未入力・不明・対象違いの件数を必ず併記してください。重複IDや対象外ID、メタデータ不一致はエラーにします。

この30件は「既存の非無作為20件＋残りから無作為10件」の混合標本です。30件の単純一致率は母集団全体の精度の不偏推定ではありません。Claudeの20件はv2開発にも使われており、独立テストではありません。本人1人の1回の評価は研究上の参照ですが、評定者間の信頼性まで保証しません。井箟ほかの書き写し一致度93%（依頼で提示された値）は作業の種類が異なり、今回の映像判定の合格基準として直接比較しません。
