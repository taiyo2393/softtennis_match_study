## 提案条件

- 対象時刻tと、その直前t−1・直後t+1に元モデルの座標がある。
- 元のtの座標が、前後2点の中点から64px以上離れる。
- 前後2点間は60px以下。速い飛行や打球直後の大きな変化を無理に修正しない。
- 同じtの別モデル成分が中点の24px以内、ピーク0.15以上。
- 支持される候補が複数あり距離差8px未満なら変更を提案しない。

対象は1フレームだけの孤立した切り替え。前後の元観測だけで各候補を独立に調べ、提案済み座標を次の修正へ連鎖させていない。
条件に合う代替成分がない場合は元の座標を残す。欠落への出力追加や、時系列だけによる検出削除はしない。
前後参照を含むオフライン処理。画像・速度・fpsへの依存がある開発条件で、一般的な運動上限とは扱わない。
892–893や960–970付近の複数フレームの飛び移り、31フレームなどの長い欠落は、この方法では解決していない。

同じ044を見て作った試作であり、外部評価ではない。過去の300標本のテスト結果を今回の独立評価として再利用せず、適合率・再現率は新しく算出していない。
過去に002の本物の球318を消した一括時系列除外は不採用のままで、この試作で復活させていない。
