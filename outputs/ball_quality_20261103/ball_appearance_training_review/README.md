# 学習側の球候補：9件の物体判定を確認済み

9件すべてユーザーがnot_ballとして保存した。CSVと全9件の回答履歴が一致し、画像と生パッチのハッシュも検証済み。`completed_review.json`に回答取り込み時のハッシュを保存した。下記manifest/protocolの未入力件数は初期状態の記録として保持する。

既存の学習側8クリップにある手動可視中心102件から、描画を加えない96×96原画像パッチを保存した。追加の教師中心は作っていない。

同じ注釈時点にある閾値0.3の元候補のうち、クリックされた対象中心から64px以上離れた9候補を確認用に抽出した。距離は確認対象の抽出にだけ用い、非ボールの教師ラベルにはしない。別の本物の球の可能性があるため、過去のwrong-target判定もgeneric non-ballの正解には流用しない。

候補の青丸内の物体を、人がball / not_ball / uncertainの3択で判定する。別の本物のボールもball。uncertainは二値分類の正解に変換しない。球中心の再クリックや球不在の判定は求めない。主プレーの開始・終了のラベルも作成しない。

`cases.json`にはフレーム、元画像、原パッチ、動画とそれぞれのハッシュを保存した。候補中心、component_indexは同一時点の元推論の出力。component_indexを時系列IDとは扱わない。クリック中心と距離を確認ページのAPIには公開しない。候補周辺96×96の生パッチに丸や文字を焼き込まない。表示用の丸はHTML canvas上だけに描く。

確認動画は対象前後最大24元フレーム、0.5倍速。対象時点は30表示フレーム分延長し、青丸を表示する。映像は1280×720を維持し上に80pxの説明帯を足した1280×800。9動画の合計1136表示フレームを復号検査済み。球の軌跡補間はしていない。

`candidate_review_labels.csv`は9件未入力で初期化した。保存時のみhuman_userとUTC時刻を付け、変更前後を`annotation_events.jsonl`へ追記する。再開時に既存回答を読み込む。`server_state.json`のURLは起動中のPCだけで利用できる。serverは127.0.0.1だけにbindし、対象9件のメディアのみ配信する。

040のユーザー否定6候補は評価側として保持し、本データに含めない。validation/auditのラベルや旧300注釈、現在の正規参照、モデル重みは変更しない。旧36候補での画像特徴実験はauditクリップを含むため、今回の学習データとして再利用しない。

回答取得後、102球中心＋9非ボールを学習に使った画像判別の固定比較を`../ball_training_only_appearance_comparison/README.md`へ保存した。評価側の正しい球を消し、040の否定6候補は残すため不採用。元の正規追跡は保持した。この収集は同一試合の選択された難例であり、未見試合への一般化や全軌跡精度の評価には使えない。
