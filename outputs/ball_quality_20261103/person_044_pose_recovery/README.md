# 044：部分遮蔽で除外された検出枠の復帰候補（2026-11-03）

**追加11観測枠がそれぞれ対応するF1・F2を囲むことをユーザー確認済み。確認済み版に反映した。**
対象は球パイロット016＝ラリー候補044。今回の明示的な回答「それぞれ対応するF1・F2を囲めている」を記録し、以前の確認を自動で引き継いだものではない。
`reviewed_person_overrides.json`の参照先は`user_reviewed/observed_player_paths.csv`へ更新した。旧確認済み1577行は全列保持し、11行だけ新しい確認を付けた。

## 原因と方法

旧方式では、手前選手の枠と大きく重なる奥選手の枠を一律除外していた。
腕やラケットを広げた手前選手の枠は、身体でない空間も含む。そのため、奥選手の見えている衣服まで隠れた扱いとなる。
元の全身枠をそのまま除外せず、身体の近似領域を除いた衣服の画素で、初期化時の同じ選手の特徴と照合する案を試した。

1. 同じ欠落の直前・直後に確認済みの選手が使っていたraw IDだけを復帰候補にする。前後位置・枠高で探索を制限するが、補間点は出力しない。
2. その時刻の手前選手をYOLO11m-poseで推定し、既存手前枠とIoU0.5以上、鼻・肩・腰のconfidence0.5以上の場合だけ対応させる。
3. 胴体の多角形、頭の円、腕・脚のカプセルで身体を近似する。正確なインスタンス分割や可視性正解ではない。姿勢が不十分な人物には枠全体の保守的マスクを使う。
4. 奥の候補枠の胴体・下半身から、そのマスク部分を除いた色ヒストグラムを作る。胴体の35%以上・20画素以上が残り、外観・負例・位置・大きさの条件を通る場合だけ追加候補にする。
5. 既存の確認済み行は全列そのまま保持。追加行は元の同時刻の検出座標で、人手未確認と明記する。

最初は手前の矩形枠をマスクし、6フレームだけ候補が出た。これを`../person_044_occlusion_recovery/`に保存した。
姿勢による身体近似へ変えた版では11フレームになった。照合・距離などの閾値は最初の案と同じで、姿勢近似の条件は`protocol.json`に残した。
同じ044を使った開発比較であり、改善の一般性や誤追加率は検証していない。
