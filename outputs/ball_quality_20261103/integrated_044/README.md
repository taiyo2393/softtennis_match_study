# 044の確認済み選手・球出力を同じ時計へ統合（2026-11-03）

**確認済み修正版の入力を変更せず、402フレームを整数source frameで結合した。**
これは追加の球5候補・968誤検出確認前の保存版。最新版は`../integrated_044_v2/README.md`。
球パイロット016＝ラリー候補044。既存の主プレー候補local739–1140、旧編集版source115374–115775を使う。
第2サービス有効は人手確認済み、正確な開始・終端は従来のAI候補区間のまま。

## 入力と座標

- 選手：`reviewed_person_overrides.json`が指す11復帰枠を含む確認済み版。
- 球：`reviewed_ball_overrides.json`が指す773・784・1103の対象球確認済み版。
- 選手の3840×2160座標を0.5倍し、球の1920×1080座標へ合わせた。映像と同じ画像座標。
- 人物・球とも`source_frame`を主キーに使用。人物時刻は全体フレーム/fps、球時刻はクリップ開始＋local/fpsで、丸め由来の微小な差があるため、浮動小数の最近傍時刻で結び付けていない。
- 人物の代表点は枠の下端中央という代理点。接地した足元、物理的なコート上の位置、身体重心を保証していない。
- 欠落は欠落として状態表へ残し、観測座標の表に補間行を作らない。
