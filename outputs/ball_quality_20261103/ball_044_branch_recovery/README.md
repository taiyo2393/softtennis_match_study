**緑の5候補が実球、968の橙が誤検出とユーザー確認済み。6時刻の変更を確認済み修正版に反映した。**
最新の球出力は`user_reviewed/predictions/match1_motion_pilot_016/balltrack_predictions.csv`。
以前の3箇所の球確認、選手経路と11復帰枠は保持した。新しい統合版は`../integrated_044_v2/README.md`。
対象は球パイロット016＝ラリー候補044のプレー中。準備中の複数球や他クリップへ適用しない。

## 方法

最高スコアの候補が離れた選手付近へ飛んでも、他の成分には前後につながる候補が残っていた。
既存の同じヒートマップ成分から、短い2区間を前から・後ろから別々に対応づけ、両方向が同じ観測を選ぶ場合に提案を出す。

- 区間local890–896、959–974を診断後に選んだ開発比較。独立テストではない。
- 両端は元のモデル出力に近い成分を初期値とする。人手の独立した球座標ではない。
- ピーク0.15以上の成分を対象に、最後の観測から`32+32×経過ソースフレーム`px以内を探索。最大間隔12フレーム、競合候補の距離差12px未満なら未割り当てとする。
- 前後両方向が反対端のモデル出力まで接続できた区間だけ使用。選んだ同時刻の成分も両方向で一致することが必要。
- 元の位置と16px以内なら元の位置を保存。別成分へ変える場合・未出力時刻に出す場合も、実際の同時刻の成分の重心だけを使う。
- 元の出力を保留する案は、両方向が接続済みで、元位置が両方向の距離ゲートの外にある場合だけ。低スコア・候補の曖昧さだけでは保留しない。
- 欠落座標を作る線形補間・平滑化は行わない。

ピクセル距離の条件はこの画像サイズ・区間の開発条件であり、球の物理的な速度上限ではない。
滑らかな別の物体へ追従する可能性は残るため、両方向一致を実球の証明とは扱わない。
過去に002・318の本物の球を消した一括時系列除外は不採用のまま。今回の局所提案を他クリップへ一括適用しない。
