# TrackNet候補特徴：全画面入力へ統一した比較

元の推論ビューの比較で、分割入力例が016にだけ偏る問題を確認した。
その結果を保存したまま、36候補の座標・正誤を変更せず、全例を元の1920×1080全画面から512×288へ入力する比較を追加した。
入力はmedian+t−3..t。元モデルは固定し、候補の64特徴による線形判別器だけを学習した。

クリップ単位の評価分離でも実球4/21保持、誤検出5/15保持となり、不採用。
元ビューと総数が同じでも、正誤が入れ替わった候補はあるため、同じ予測結果ではない。
016だけで学習し他8例へ適用する条件では実球0/3を落とした。
これら少数・偏った既知例での失敗を、時系列情報全体の有効性がないという結論へ広げない。

`effective_sequence_cases.json`に元の注釈ビューと統一した入力ビューの両方を残した。
全画面016の22入力について、再推論ヒートマップと既存キャッシュの最大画素差0を確認した。
前後4画像のハッシュも訓練・評価で交差しない。元重み・人手確認結果・注釈は保持している。
