## 外観判別の固定試作：不採用

`appearance_probe_v2/`に、044だけで学習した単純な画像特徴の線形分類器を保存した。
候補中心16/32pxの勾配方向ヒストグラムと4/8/16/32pxのBGR平均・標準偏差、計672特徴。
座標・時刻・検出強度・クリップ番号・時系列選択結果は特徴へ入れない。
標準化は訓練28例だけで計算。クラス重み付きロジスティック損失＋固定L2正則化、パラメータ探索なし。
既存環境にsklearnがなく、OpenCVの最小構成にはHOGDescriptorもないため、依存関係を追加せずNumPyで指定した勾配ヒストグラムを実装した。
失敗した初期化試行は`appearance_probe/`に保存。初回は学習・予測前の環境エラーであり、結果を見た設定変更ではない。

既存の別クリップ反例では実球1例を落とし、手への誤検出3例をすべて保持した。
この試作は安全性の最小確認を満たさず**不採用**。同じ044にだけ合わせた画像判別をそのまま全区間へ適用しない。
この4件は準備・切り替えの既知例なので、この成否をラリー中の一般的な精度として報告しない。
