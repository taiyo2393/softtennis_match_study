# 元の推論ビューによるTrackNet特徴の候補判別試作

球追跡モデルの元重みを固定し、predictor直前64特徴を候補中心の出力格子3×3から平均した。
既存の36確認候補で小さな線形判別器だけを学習。比較条件は手作り・ResNet特徴と同じ損失・正則化・クリップ分割。
元の球検出器・BatchNorm統計・確認済み追跡結果は更新していない。

元クリップを一つずつ評価側へ回す比較では、実球4/21を保持、誤検出5/15を保持し、不採用。
ただし全12分割入力例が016だけにあるため、016を評価へ回すと訓練には分割入力例がなくなる。
このスケールとクリップの偏りを時系列特徴そのものの効果とは解釈しない。

追加の全画面統一比較を`../ball_tracknet_common_view_comparison/`へ別実験として保存した。
最初の条件・実装は`protocol.json`と`original_implementation.py`に保持している。
この試作に既存300件の球中心注釈は使っていない。中心注釈の手動作成が確認された後の本来の検出器の追加学習とは別である。
