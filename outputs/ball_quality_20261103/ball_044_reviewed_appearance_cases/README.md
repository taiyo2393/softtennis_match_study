# 044：既存の球候補確認から作った外観比較用データ

実球を囲むと確認された18候補と、実球を囲まないと確認された10候補を候補単位で書き出した。
すべて既存の明示的なユーザー回答に由来し、新しいラベル付け・未確認候補の負例化・欠測の負例化はしていない。
緑の置換候補を正しいと確認しただけの古い回答から、元座標も誤検出だったとは推定していない。

- `cases.csv`：候補ID、フレーム、確認済みラベル、座標、推論方式、レビュー記録、元画像とパッチのハッシュ。
- `patch96/`：元画像の96×96pxをそのまま保存した候補周辺画像。
- `context224/`：同じ中心で224×224pxを保存した文脈画像。
- `reviewed_counterexamples.png`：1089実球、1091-B実球、1091-A誤検出、1092-A誤検出の既存確認例を比較した図。
- `manifest.json`：出典・ハッシュ・用途制限と検証結果。

画像は1920×1080の既存JPEGから切り出したPNGで、超解像や生成による補完はしていない。
PNGを書き戻して元の切り出し配列との一致を全56枚で検査した。確認済み入力・元画像・ラリー注釈は保持した。

ラベルは「指定された丸が実球を囲むか」であり、精密な中心座標やフレーム全体の球の可視性の正解ではない。
一つのフレームに実球候補と誤検出候補が同時に存在するため、IDに推論方式・候補情報を含めて区別する。
同一フレームの別位置や別推論方式へ正誤を伝播していない。

**全28候補が同じ044のラリーに由来する。** `split_group`は全行`legacy_match1:rally044`。
隣接フレームや同じ候補の別切り出しを訓練とテストへ分けて独立精度としてはならない。
現時点では確認例の比較・失敗解析用で、分類器の学習や独立性能評価は行っていない。
次の分類比較には、別ラリーの確認例・保留状態・同じ出力条件での比較対象が必要。
