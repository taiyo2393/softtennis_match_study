# 学習側だけから整理した大きな位置誤り

学習用120標本だけを対象に、手動中心がvisibleで、元モデルの検出がその中心から64px超離れる例を抽出した。
001/336と009/599の2件。`far_wrong_target_predictions.csv`に元の点・対象中心・出典を保存した。

ラベルは「その手動注釈対象の位置として誤り」。誤位置に別の実球がないことや、物体が手・ラケットであることは未確認。
候補分類器の一般的な非球画像として自動的に使うことはしない。
元フレームと中心注釈に基づく学習側の難例サンプリング・目標損失の検討用で、モデルの再学習はこの抽出段階では実施していない。
設定選択・後段点検の難例を学習へコピーせず、それらのラベル・正規出力も保持した。
