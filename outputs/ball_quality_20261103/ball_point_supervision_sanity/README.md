# 9画像の点を学び分けられるか：学習側だけの成立テスト

本比較で、確認済み非ボール9点の応答を学習後にも十分下げられなかったため実施した。実用モデルを選ぶ追加試験ではなく、学習の成立を調べる診断である。実施前に`protocol.json`を固定した。

同じ学習側9画像（5クリップ）にある実球中心9点と非ボール中心9点を使用。各画像で両者のBCEを0.5ずつ足し、その他の画素には損失を課さない。元モデルから初期化し、最終デコーダ/予測層だけ、FP32・Adam1e−4・batch3で100更新した。元応答保持、全画面の背景教師、データ拡張、途中での回数や閾値の選択はない。

| 学習点での応答 | 元モデル | 100更新後 |
|---|---:|---:|
| 実球9点のうち0.3を超える | 8 | 8 |
| 非ボール9点のうち0.3を超える | 8 | 2 |

最終的に実球>0.3かつ非ボール<=0.3となった組は6/9。平均は実球0.612、非ボール0.207。学習信号は伝わる一方、この固定100更新では全9組を学び切っていない。点が正解でも物体全体のヒートマップ、検出座標、全画面の誤出力が適切とは限らない。

本比較から元応答保持と露出頻度を同時に変えたため、失敗原因を一つへ特定する対照実験ではない。元の102画像へ戻したときの一般化を評価しておらず、この診断の結果から損失係数や学習回数を後付けで選んでいない。診断用差分モデルは`diagnostic_only_delta.pth`として実用候補から区別した。

validation、challenge、短区間、6否定候補、auditには適用していない。元の重み・ラベル・モデル比較結果・正規参照の不変を検証し、結果は`result.json`と全100更新の`training_history.csv`、初期/最終`point_scores.csv`に保存した。
