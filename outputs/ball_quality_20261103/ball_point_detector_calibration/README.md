# 追加学習モデルの閾値を学習側だけで選ぶ比較：適格設定なし

固定済みの2モデルについて、0.3/0.4/0.5/0.6/0.7/0.8/0.9/0.95の8閾値を既存の学習側123時点だけで比較した。全16設定に「元の正解66件を全て保持し、誤出力4件以下」を満たすものはなかった。元のモデル・固定時系列方式を保持し、新方式による評価側への適用は行わない。

正解数が増える条件自体はある。今回の誤出力を増やさない採用条件を満たさなかったのであり、全設定が全指標で劣る、又は全ての連続した閾値で改善不可能という意味ではない。

## 新しい開発実験としての位置づけ

前回の点教師による追加学習では、出力の反応範囲が広がり、元の固定閾値0.3で誤出力が増えた。前回の条件・失敗を上書きせず、**閾値だけを学習側で選ぶ別実験**として`protocol.json`を新しい推論前に固定した。

対象は以前に固定済みのpositive_controlとpoint_negativeの最終epoch3差分だけ。9画像の学習成立テストの診断モデルは含めない。重み・学習回数・損失・入力間隔の変更や新規学習はない。

輪郭、矩形中心、displacement0.1の経路選択、カメラ保留はそのまま。対象画像を末尾とする連続4画像を使い、候補選択は前後8元フレームを2刻みで参照するオフライン方式。変える値は二値化の閾値だけである。応答値を校正済みの正解確率と扱わない。

## 事前に固定した選択

元の時系列方式（学習側66正解・誤出力4）を候補に含める。追加学習モデルは、元の正解66件を全て保ち、誤出力4以下なら適格。その中で正解数最大、誤出力最小を優先し、厳密な改善がなければ元の方式を残す。同点は元の方式、対照、列挙した小さい閾値の順。

選択できた1つだけを固定してから評価120件・4challenge・短区間26へ適用し、失敗後の別設定への切替はしない。選択可能な改善設定がなければ、これらと否定6候補・auditへの新規推論に進まない。モデルや閾値を選んだ後に負例9点の効果へ無条件に帰属しない。

全16件は`training_threshold_grid.csv`。`training_tradeoffs.csv`に正解数と誤出力数でのPareto関係も保存した。正解を増やして元の正解も保つ対照0.7はあるが、誤出力が4→12へ増える。誤出力を元程度へ下げると、今回の候補では元の実球を複数落とした。

非ボール追加0.7は正解合計66が同じでも、元の正解003/291を失い、別の時点を回復している。「同じ正解数」を「全ての元の正解を保った」と混同しない。

全16設定が不適格のため、今回の新しい評価側予測は0件。以前の評価結果が未使用の独立テストになったわけではなく、学習・評価とも繰り返し見た同一試合の開発データである。

## 点の応答順位の診断

同じ9学習画像の手動実球中心と非ボール中心を比較した。実球点の応答が非ボール点より高い組は、元モデル・対照・非ボール追加の全てで6/9だった。平均差は元+0.0844、対照+0.00955、非ボール追加+0.0391。

例えば003/291の非ボール追加モデルは、手動実球点0.494、非ボール点0.780。単一の閾値を変えるだけでは、この2点の応答順位を逆転できない。この点の比較では学習の識別にも課題が残る。

ただし、これは双線形サンプルでの学習点の応答比較。矩形中心と物体上の最大値、成分の形、時系列の経路によって最終座標は変わるので、点の順位だけから全ての物体検出や追跡で改善不可能とは結論しない。詳細は`training_point_pair_order.csv`。

## 正確な再二値化と検証

0.3以上の再二値化用に、元の0.3成分の**全矩形内の画素値**を保存した。0.3を超えた画素だけでなく、矩形内部の低い値や穴も残すため、高い閾値で成分が分かれた後の矩形平均も維持できる。矩形外は0へ戻す。これは0.3未満の探索には使えないキャッシュである。

2モデル×1107文脈時点＝2214時点を保存し、全時点で0.3の候補・中心・平均等が再現することを検査した。0.3での学習123時点×2モデルの最終座標・出力有無も前回の246予測と完全一致。穴や分裂成分を含む合成マップで8閾値×3枚の候補情報が完全一致することも確認した。

最初の埋込テストは合成マップの穴へ丸めていないFP32の0.1を入れたため、精度を黙って失わない保護で拒否された。実推論はAMPのFP16値なので、この不一致は本データで発生していない。実行したソースを`executed_source.py`へハッシュ付きで保存し、終了後に合成テストの0.1だけをFP16へ丸める修正をした。推論・閾値・選択・結果は変更していない。

圧縮配列の検査は各配列を一度だけ解凍して実施する。検査の再開は検証処理のみで、推論やパラメータ選択を再実行していない。モデル差分・元の重み・旧300注釈・人手回答・レジストリ・元画像の不変は`verification.json`に保存した。

## 判断

今回は、試した2モデル×8閾値の範囲で、閾値の変更だけでは採用条件を満たさないことを確認した。追加学習の問題を固定0.3だけに帰属せず、学習点で実球と非ボールの応答を分離できているか、未注釈画素の出力形状が保たれるかを次の検討対象とする。途中の結果を見て0.7の近辺へ閾値を追加したり、評価側へ合う条件を選んだりはしていない。

再学習・新規人手入力・補間・物理的球不在教師の推定・正規追跡の更新は0件。卒論での性能主張には、この既知の学習側比較と独立な評価を分ける必要がある。
