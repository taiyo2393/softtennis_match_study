# 044：暫定バウンド位置のコート投影

既存のバウンド候補B01・B02について、その代表フレームの球中心を地面上と仮定してコート図へ置いた。コート校正・候補フレーム・元の人手整備球中心は変更していない。現在の空中球を平面へ投影した連続軌道や、検証済みの実測落点ではない。

## 表示

`044_bounce_candidates_half_speed.mp4`は、従来と同じ213元画像・同じ元フレーム対応で半分の速度の動画。左の緑はその時点の画像上の球と短い軌跡、右の橙の輪は地面上と仮定したバウンド候補点。

候補点はその代表フレームで初めて表示し、以降は既出の固定点として残す。今の球を示す動く点ではない。左画像の橙輪も短い間だけ固定した代表位置を示す。空中の球の画像位置と混同しないよう説明を付けた。

- B01：F115415。1打目の有効サーブの後、2打目のN2返球より前。従来の暫定バウンド区間はF115413〜115419。
- B02：F115571。3打目のF1返球の後、4打目のN2返球より前。従来の暫定区間はF115569〜115575。

`two_bounce_candidates_on_court.jpg`は2枚の球付近の画像と、同じコート図上の2点を並べたもの。暫定点ではB02の方がB01より右側にある。球が右へ配球された可能性とN2の返球位置の変化を見比べる材料にはなるが、狙い・戦術的効果・失点原因を証明する図ではない。

## 投影の条件

元球中心は1920×1080。既存のコート校正は3840×2160なので、画像x・yを2倍してから同じホモグラフィで変換した。コート座標は、左ダブルスサイドラインx=0、右x=1、手前ベースラインy=0、奥y=1。

| 候補 | 地面上と仮定したx | 同y | 確認状態 |
|---|---:|---:|---|
| B01 | 約0.650 | 約0.314 | AIのバウンド候補、時刻・位置は未確認 |
| B02 | 約0.853 | 約0.259 | 同上 |

この数値はコート幅・長さで正規化された条件付き投影点。小数桁は精度保証ではない。境界へ丸めず、イン・アウト判定やメートル単位の距離・速度へ使っていない。球中心と実際の地面接触点の差や球の高さを補正していない。代表フレームが正確な接触時刻とは限らず、その時間ずれも投影誤差になり得る。

入力球位置は以前に予測を見て人が確認・修正した値で、独立した中心正解ではない。今回の打球順の人手確認はサーブを含む5打球とF1→N2→F1→N2→F1の対応のみ。バウンドや位置精度の人手確認へ拡張していない。

## 入れていない情報

空中球の真下の位置、見えなかった奥側バウンド、最後のアウトの落点を作って埋めてはいない。球の3次元軌道・高さ・物理速度も推定していない。打球者の足元代理点とバウンド点を結んだ線を、実際の飛翔軌道として表示することもしていない。

未確認の点を空欄のまま残す既存の球・人物表は保持し、新しい条件付き投影は別CSVに保存した。正式な球中心・ラリー・得点側・学習入力を更新していない。

## 保存物と検証

- `conditional_bounce_court_points.csv`：2候補の元画像座標、仮定付きコート座標、元の候補区間と未確認フラグ。
- `source_image_manifest.json`：元画像とハッシュ。
- `protocol.json`：出力を見る前に保持した候補・処理条件・入力ハッシュ。
- `video_source_frame_map.csv`：動画全213フレームと旧編集版source frameの対応。再ダウンロード後の動画へ同じ番号を直接シークしない。
- `verification.json`：過去3段階の成果物不変、2点の元球座標一致、1920→3840のスケールを組み込んだ別のOpenCV計算との一致、動画の全フレームデコードを検証。これは算術・由来の検証であり、着地位置精度の評価ではない。

再実行コードは`executed_source.py`。`prepare`→`build`→`render`→`verify`。既存の実験ディレクトリは上書きせず、新規の出力先で再実験する。
