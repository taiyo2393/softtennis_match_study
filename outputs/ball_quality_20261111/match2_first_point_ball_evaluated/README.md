# match2 第1点の球追跡評価

予測を表示せずに記録した12時点の参照を、推論済みの基準モデルと照合した。球が見えた10時点すべてで候補があり、既存の16px基準内だった。中心差の中央値は2.24px、最大は4.12px。

球が見えないと回答した2時点のうち、F12393には候補があり、F12437は出力がなかった。F12393の前後を拡大すると、黄色い球らしい像がネット上端を通過する。該当時点の候補の実球同定は未確定で、本人の参照は「見えない」のまま保存した。

全243フレームでは199時点に候補があり、44時点が未出力だった。球の有無と位置を照合した範囲は、事前固定した12時点と第1点の1ラリー。球が見えた参照10時点に欠測がなかったため、この標本では欠測補助の効果を比較できない。
