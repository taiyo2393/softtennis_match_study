## 奥の予測方法と失敗結果

球位置がないF115475〜115499、F115693〜115711の2区間を対象にした。欠測直前の最大24元フレームと、欠測直後の最大24フレーム（次の打球候補前で打ち切る）から観測球位置のみを使う。前後に同じバウンド点を共有する折れ線xと、連続な区分二次曲線yを当て、欠測内の各整数フレームをバウンド時刻候補として比較した。画像yは下向き正なので、バウンド直前は下降、直後は上昇し、その前後で下向きの曲率を持つという制約を置いた。これは画像上の近似で、空気抵抗や重力を推定した3D物理モデルではない。

最初の制約なしの結果はコートy=約1.097・1.132となり、両方が奥ベースライン外だった。`far_fit_models.json`と全時刻候補の残差表に保持し、正しい落点とは採用しなかった。

その後、返球が続くこの区間では奥コート内にバウンドした、と仮定する比較を追加した。奥半面x=0〜1、y=0.5〜1の範囲を画像上の4つの不等式にして、元の曲線と同時に制約付き最小二乗で解いた。出力を後からコート内へ丸めた処理ではない。時刻候補、使う観測、曲線の次数や窓幅は変更していない。

**両点がベースライン上なのは、実際にライン上へ落ちたと確認できたためではない。コート内という仮定に対し、モデルが制約の境界に達した結果である。** 単純な画像近似・欠測・校正・球中心の誤差などを分離できておらず、奥コートの左側・ベースライン付近という粗い予測以上には扱わない。境界に達する結果はモデルと仮定の緊張を示している。

制約なし／ありの画像残差RMSは約6.07→6.08px、2.27→2.28pxで、画像への合い方をほとんど変えずに落点が変わる。小さい当てはめ残差は着地位置が正しい証明ではない。全候補のプロファイルと、最小RMS+1px以内に入る時刻の感度範囲も保存したが、統計的な信頼区間ではない。
