# 056：局所画像入力による再取得比較

1920×1080の既存キャッシュから960×540を切り出し、512×288へ入力した。全体画像入力に比べて球の画像上の大きさは2倍になるが、周囲の文脈も変わるため、解像度だけの効果とは断定しない。重みと成分閾値0.1、探索半径32pxは固定し、追加学習や条件探索は行っていない。

欠測10時点中、F154270と154324の2時点に未確認候補が出た。F154780にも以前の誤検出とは別位置の候補が出ているため、診断対象として別途確認する。以前の赤丸が誤りという回答から、新しい位置の正しさは判断できない。

確認済み19時点を入力すると18時点に候補が出たが、F154853は未取得となった。18点とも実球という新しい確認はまだなく、座標差は検出精度ではない。既存出力の全面置換は行わず、欠測時の補助手段として検討する。

探索位置には人手整備済みの前後位置を使う。完全自動・独立試験ではない。原画像・注釈・旧出力を保持し、新候補の本人確認前には確定データへ追加しない。
