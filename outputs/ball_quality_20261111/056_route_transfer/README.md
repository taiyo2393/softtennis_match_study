## 044から保持したもの

方向変化候補は、連続5可視サンプル・2元フレーム間隔・画像速度0.5px/元フレーム以上・45度以上・候補間12フレーム以上。056では15候補が出たが、そのまま15打球とは扱わない。

欠測を含むバウンド推定は、同じ`matrices`・`constrained_y`・`solve`関数を呼び出した。前後最大24元フレーム、xは連続区分直線、yは連続区分二次、下降→上昇・下向き曲率という同じ制約で、欠測内の整数時刻を比較した。コートの対象半面は、受け手が手前か奥かに従う。同じコート多角形制約を用い、044の「奥」だけを固定値でコピーしない。

短い補間も同じ12元フレーム以下・同一飛翔区間だけで実施。打球・バウンド候補をまたがない。本人追跡、コート校正、球中心を再学習・再選択していない。

打球・バウンドの候補区間は、固定した全区間の一様時系列画像と拡大画像をAIが点検して提案した部分であり、自動イベント検出の成功として数えない。13打球のうち各区間のボレー候補には着地点を作らず、模式線は打球者代理点から次の打球者代理点へ直接つないだ。これは3Dの飛翔軌道や実測の真下の軌跡ではない。

## 単独の球位置の飛び

F154780の元球位置は(1102,579)。両隣F154778の(918,526)、F154782の(952,531)の中間点から約174px離れる。この単独の飛びが方向変化候補C14を作っていた。元データは予測を人が明示採用したものだが、採用済みだから座標が常に正しいとは扱わない。

`AI_ball_position_warning.json`に疑いとして保存した。赤丸で元の点を表示し、そこへの軌跡線を結ばない。両隣の中間位置を真の球へ置き換えていない。これは今回のAI点検による表示上の警告で、未見データに有効と検証した新しい自動フィルタではない。元の中心・採用回答・正規参照は変更していない。

この1点の本人確認用に`F154780_ball_identity_review.mp4`を作成。全体と固定範囲の1.5倍拡大を並べ、4分の1速・対象フレームで停止する。47表示フレームの元画像対応を保存し、未修正の赤丸がラリーの実球かどうかだけを問う。回答を前後の中心位置・13打球の順番・厳密な座標の正解へ広げない。
