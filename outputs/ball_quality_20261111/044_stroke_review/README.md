# 044：AIによる一打ごとの暫定整理

## 今回の到達点

前の方向変化4候補だけに絞らず、固定済みサーブ〜終端候補区間を6元フレーム間隔で時間順に点検した。続いて7か所の元画像を拡大し、毎元フレームの短い動画と2フレーム間隔の画像列を保存した。

表示区間内の打球者は、サーブを含めて **F1 → N2 → F1 → N2 → F1** の5打球というAI暫定解釈になった。新しい人手確認や、自動打球検出の成功数ではない。末尾のラリー終了時刻も元から暫定であり、区間外を含めた完全な打球総数を確定したとは扱わない。

`044_AI_stroke_sequence_half_speed.mp4`に、一打の候補区間・打球者・次打球者の候補を、従来の配置・球軌跡と同期して表示した。元の164球位置・37欠測・12未注釈時点、人物の欠測は保持した。

|---|---|---|---|
| H01：有効サーブ | F1（奥・赤白） | F115365〜115373：以前の区間を継承 | N2 |
| H02：返球 | N2（手前・黒） | F115437〜115445 | F1 |

有効サーブ・手前得点・アウト終了は既存の人手回答。今回の4返球の種類・打球者・時刻はAIの所見で、人手確認へ昇格させていない。F1/F2/N1/N2はこの区間の追跡スロットで、他の試合・カメラ・区間に同じ人物対応を引き継がない。

## 方向変化4候補との違い

- C01/F115415：バウンド候補B01。N2が振る前に低い球が下降から上昇へ変わる。打球H02はその後。
- C02/F115509：打球と認定しない。奥F1はまだ準備中で、スイング候補は後のH03。低速の画像上の球位置が小さく方向変化しているが、放物の頂点付近か座標の揺れかは未解決。無理にバウンドにも分類しない。
- C03/F115571：バウンド候補B02。N2が移動中に球が低くなり、その後上がる。打球H04はさらに後。
- C04/F115727：H05のスイング候補区間に重なる。元の画像上の最寄り枠は手前N1だったが、前後の拡大画像では奥F1の打球という解釈。最寄り人物を打球者へ直結させない。

これはAI解釈による構造の点検であり、「方向変化4候補中1正解」「5打球中1検出」等の適合率・再現率は算出しない。AIの暫定表を自動検出の正解として使うと循環評価になる。

## 一打表の座標の意味

`AI_stroke_records.csv`は5行の一打表。各行の代表フレームは暫定接触区間内の表示・結合用の時点であり、正確な接触フレームではない。

- 打球者の「位置」は、その代表時点の人物枠下端を既存のコート校正で投影した代理点。ラケット接触点・実測接地点・ボールのコート座標ではない。
- `stroke_player_snapshot_proxies.csv`は5時点×4選手の20欄。元観測のある19点だけを保存し、H02代表F115441のF2欠測1点は空欄を維持。
- 代表5時点のうち、球位置があるのは2時点。H01は注釈対象外、H02/H03は球位置が欠測。人物のスイングが見えても、その時点の球位置を補間していない。
- `next_hitter_candidate`は次の打球者との暫定対応で、着地点ではない。実際の打球点・落点・球の高さ・速度・3次元軌道の欄は空欄。
- `sampled_image_flights.csv`は暫定打球区間の間にある、同じ元フレームの球位置・欠測を抽出した表。画像上で左右へ進む傾向を添えたが、物理的な打球方向角や連続した飛翔経路を推定したわけではない。

球のない区間には、奥側でのバウンドを含む可能性がある。`ball_missing_interval_inventory.json`に欠測を残し、イベント時刻や球の不在を作って埋めない。

## 研究として言える範囲

この1ラリーでは、奥F1と手前N2の返球の往復という暫定的な展開を、配置と球軌跡に結び付けて整理できた。最終的なアウトをどの打球者・狙い・技術的要因に帰属させるかは未確定。F1の失点原因、N1/F2の戦術的意図、一般的な配球傾向は断定しない。

手作業で球を整備した既知の同一試合の1例をAIで点検した試作であり、自動化の達成や、他ラリーへ一般化する精度評価ではない。次に本人確認を得る場合も、「打球順・打球者の確認」と「厳密な接触時刻・着地点の参照」を分ける。前者の回答を後者の正解へ拡張しない。
