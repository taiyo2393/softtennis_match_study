# 056：隠れによる選手代理位置の飛びを抑制

右側コート図の人物点を清掃し、左側の選手枠も同じfilter_statusの判定に合わせた。元JPEGから元の描画を再現し、球位置・軌跡・打球表・バウンド・配球線の入力と描画を維持。今回の変更を認められたレンダラ以外の既存スクリプト・保護対象ファイルはSHA-256一致を確認した。動画は1920×1080、401フレーム。再圧縮による画素差は生じうる。

4選手に同じ規則を適用。枠高さが直前の採用点（最大15点）の中央値の0.75倍未満・1.35倍超なら棄却。採用が5点に達するまでは当該選手の入力全体の中央値を参照する。ただし、高さ棄却が生の観測点の順序で連続し、先頭と現在点の差が30元フレームを超えたら、その区間を先頭から再判定する（ちょうど30では戻さない。元から欠測の点は連続を切らず、復帰対象にしない）。区間の高さの中央値をリセット時の参照値とし、古い高さ履歴を破棄して復帰点の高さ（直近最大15点）で作り直す。その後の点は新しい基準で通常判定する。復帰点はobserved_after_height_resetとする。復帰時も直前の採用点からの速さ規則を維持し、さらに直前の生の点からの移動が同じ速さ規則を破る点をrejected_speedにする（区間への入り口および異常点から戻る移動も検査）。復帰できる点がない場合にも区間の高さで基準を更新し、速度判定は継続する。直前の採用点からの距離が8 m/s×経過秒＋1.0 mを超える場合も棄却（高さ判定を優先）。元動画59.94 fps、メートル換算はx×10.97、y×23.77。両端の採用点が30元フレーム以内（約0.5005秒）の欠けだけを表示フレーム上で線形補間する。端点のない区間は補わない。

右図では塗りつぶし円は採用点、同色の白抜き円は補間点。最終statusが棄却・欠測の点、および表示範囲外の点は右図に描かない。表示範囲は元と同じx=(-0.25, 1.25)、y=(-0.3, 1.55)。範囲外等による描画省略は0点。

CSVのstatusは補間後の表示状態。filter_status（および互換用input_status）にリセット後・補間前の判定を残し、rejected_speedの点も既存の短区間補間規則を満たせば最終statusはinterpolatedとなる。raw_previous_frame、raw_jump_m、raw_speed_limit_mは生の点どうしの移動の監査用で、height_reset_start_frame/trigger_frameは再判定した区間を示す。court_proxy_x/yは入力をそのまま保存した。件数は各選手401行、計1604行について集計。

高さリセットによる復帰は合計34点。N1：17点、N2：17点、F1：0点、F2：0点。区間の開始・発動フレームと速度棄却点はsummaryのheight_resets_by_playerに記録した。

限界：補間点は観測ではない。両端の採用点が30元フレームより離れた欠測は補間しない。長い高さ棄却を大きさの変化と扱う規則は仮定であり、長い隠れも復帰させる可能性がある。filter_statusには棄却理由またはmissingを残し、短区間補間された行の最終statusはinterpolatedとなる。足元の位置精度は検証していない。隠れの検出器ではなく、枠高さと移動量によるヒューリスティックであり、正常点の棄却や異常点の通過、ID誤りの残存はありうる。速度閾値は推定された真の走速度を保証しない。
