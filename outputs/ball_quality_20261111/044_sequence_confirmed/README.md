# 044：打球順・打球者の人手確認と配置の記述

ユーザーの「合っている」を、サーブを含む5打球と打球者順 **F1 → N2 → F1 → N2 → F1** の確認として記録した。質問全文・回答・質問ID・確認対象動画のハッシュ・対象範囲は`human_sequence_confirmation.json`に保存した。

これは1本の表示動画に対する1回の確認で、5つの独立ラリーの精度評価ではない。予測された打球順を示して確認したもので、盲検評価でもない。接触フレーム、バウンド、球中心、位置精度、全フレームの人物対応まで確認されたとは扱わない。

## 確認後のデータ

- `confirmed_stroke_sequence.csv`：打球数・打球者順のみ人手確認済みにした5行。時刻区間と代表フレームは元のAI暫定値のまま。
- `unchanged_reference_player_proxies.csv`：各代表時点の4選手、計20欄。観測19点とH02のF2欠測1欄を元のまま保持。
- `reference_arrangement_diagnostics.csv`：5代表時点すべてでの、手前・奥ペアの画像枠由来コート代理点の間隔。相方のないペアは空欄。
- `all_consecutive_reference_proxy_changes.csv`：全4区間×4スロットの代表点間変化。片方がなければ差分も空欄。連続軌跡や物理速度ではない。
- `confirmed_sequence_arrangement.jpg`：5時点を横に並べた比較。ベースライン外の代理点も端へ丸めず表示した。

旧`044_stroke_review`の39成果物、暫定表・動画・座標はハッシュで不変を確認した。旧AI所見を削除せず、今回の人手確認を別の派生表として付け加えた。ラリー得点側・球の正規参照・current22入力を更新していない。

## 配置から読めること

代表時点の代理点では、N2のxは2打目でコート左から約66%、4打目で約95%。同じ2時点の手前ペアの左右間隔は、コート幅に対し約29%から約72%へ広がっている。奥F1の3・5打目は左側である。

この5時点のすべてを図示し、最大変化だけを成功例として抜き出していない。数値は人物枠下端の投影点の差であり、足元の物理精度が検証された距離ではない。接触の正確な瞬間の配置や、途中の走行経路を測定したとも扱わない。

現段階で記述できるのは、「このラリーではF1とN2が打ち合い、N2の返球位置が右側へ移った。その間に手前ペアの左右間隔も変化した」という展開。球が正確にどこへ落ちたか、F1が意図して空いた場所を狙ったか、その配置が得失点の原因だったかは未確定である。

今回の確認で、最後の打球者がF1であることは確認対象に含まれる。以前の「アウト終了・手前得点」と組み合わせて時系列上の結果を整理できるが、アウトの落点や技術的原因を新たに断定しない。

## 次に必要な情報

一打ごとの展開の記述を進めるには、打球後の球位置・バウンド候補・次の打球までの対応を保ち、欠測と暫定位置を明示する。戦術的な有効性や繰り返す弱点を論じるには、他ラリーとの比較と競技者による評価が必要。この1点から相手の一般的な弱点や推奨作戦を決定しない。

`verification.json`は人手確認1件・5打球者行・新しい厳密時刻0・新しい位置正解0を分けて検証した記録。`executed_source.py`で新規スナップショットを作り、文字位置だけの調整は`--redraw-only`で確認・数値の5ファイルがバイト単位で不変であることを検証した。旧レイアウトも保存している。
