# 044：選手配置・球軌跡・事象候補を同期させた試作

## 今回作ったもの

`044_synchronized_half_speed.mp4`で、同じ元フレームの映像・4選手のコート配置・球の画像軌跡・事象候補を一緒に表示する。単に枠の出現数を増やす試験から、ラリーの展開を確認できる入力へ進めるための試作である。

- 左：既存の選手枠と、人が確認・修正した球位置。緑線は直近約0.6秒の画像上の球軌跡。球の欠測や未注釈をまたぐ線は描かない。
- 右：人物枠下端の代理点を、既存のコート校正で平面図へ投影した位置。足元の測定精度を新たに検証した座標ではない。4人が揃わない時点は欠測を表示し、直前の位置を保持して埋めない。
- 下：既存の暫定サーブ・終端区間と、新たな球の方向変化4候補。方向変化を打球・バウンドと確定したものではない。

球は空中にあるため、コート平面の変換をそのまま適用していない。右の図に球の点や推定落点は表示しない。球の高さ・3次元軌道・物理速度・予測着地点も未取得である。

## 事象候補の意味

球位置のある連続5時点だけから、前後それぞれ3点の画像速度の方向変化を求めた。速度0.5px/元フレーム以上、45度以上の方向変化、候補間12フレーム以上という未検証の試作条件を、新たな候補出力を見る前に固定した。結果を見て閾値を変えていない。欠測を補間して方向変化を作らないため、球が見えない打球の検出はできない。

候補はF115415・115509・115571・115727。`all_direction_change_candidates.jpg`に全4件の原画像拡大を保存した。バウンド、打球、追跡位置の揺れをこの条件だけで区別したとはしない。候補が4件あることを4打球の検出成功と数えない。45度未満の打球や欠測を含む打球も取り逃し得る。

球と人物の画像枠との近さも診断値として保存した。ただし、奥の選手の打球付近で手前N1の枠が画像上で重なり、近い選手が実際の打球者と一致しない可能性がある。`nearest_player_slot`は近接候補であり、`hitter_confirmed`は全件空欄。方向変化と最寄り人物だけで一打単位の記録を完成扱いにしない。

サーブ有効・手前得点・アウト終了は既存の人手回答を再利用した。接触F115365〜115373、終端F115776〜115790は以前のAI暫定区間で、正確な接触・着地フレームの人手確認ではない。先行するファーストサーブのフォルトは同じポイントの別試技として元記録に保持し、今回の主プレー表示には混ぜていない。アウトの打球者・落点・線・失点原因を新たに確定していない。

## 現時点で言えることと次の作業

短い区間で、選手配置と球の観測軌跡を同じ時刻で確認できる形にはできた。自動戦術分析の完成、足元・球の物理位置精度の達成、打球検出の精度改善、失点原因の解明を示した結果ではない。

次に必要なのは、方向変化候補を実映像の前後で点検し、打球・バウンド・不明を分け、打球者の対応と未取得の打球を整理すること。球と人物の画像上の近さだけには頼れない。検証用の参照とAIの暫定所見を分けたまま、一打ごとの入力表へ進める。
