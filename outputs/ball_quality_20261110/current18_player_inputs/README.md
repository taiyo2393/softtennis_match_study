# 配置入力18候補：014の序盤を追加

014の従来処理による固定序盤入力を追加した。全18候補、固定30候補群内では15件作成・15件未処理、次は015。得点側の人手確認は11件（手前7・奥4）のまま。008〜014の7件は空欄であり、機械の得点表示候補から補っていない。18件を正解付き分析適格ラリー数や、自動追跡の成功数とは数えない。

014は旧台帳の接触時刻を継承し、F36380の30〜90フレーム後、F36410〜36470の31時点を要求した。元の接触記録の時間精度は不明であり、新たな1フレーム精度の正解ではない。原画像の連続表示ではプレー中の区間と整合している。手前左サーブという属性は得点前の原画像からのAI候補で、由来と画像ハッシュを保存した。

014の指定31時点にはすべて4候補があり、手前・奥の観測率は31/31、指定末尾も両ペアの観測あり。全時点のID付き画像をAIが点検し、明らかな人物の入れ替わりは見られなかった。ただし、本人同定や地上位置の独立した精度評価ではない。固定入力直後には奥F2の35フレーム欠測があるため、序盤の完全観測をラリー全体の追跡成功としない。

同じ検出枠による固定ガード比較では、全区間の割当と序盤の配置値は従来処理と同じだった。手前の検出ID変更自体がなく、今回の結果を誤連結防止の新たな成功例に数えない。試作は別保存し、入力は従来処理を由来とする。

比較用5ファイルの候補・順序は同じ18行。旧17件の値と欠測、009・011の個別修正の由来、確認済み11ラベル、固定16件の得点検証標本を保持した。`human_outcomes.csv` は未確認も含む台帳、`confirmed_human_outcomes.csv` は確認済み11件だけ。未確認の旧監査項目は上書きしていない。

位置は検出枠の下端に基づく画像座標で、遮蔽時の部分枠は地上位置として偏り得る。奥側の経路探索は後続映像を使うため、序盤位置だけを入力列にしてもオンライン処理にはならない。同一試合での開発という制約も残る。今回も学習・性能推定・球追加比較はしていない。
