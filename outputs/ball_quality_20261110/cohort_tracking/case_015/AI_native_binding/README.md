# 015：AI個別指定による審判の割当修正

自動出力と固定済み再取得ガードは、N1として右端の審判を追っていた。元の失敗出力を残し、実際の手前右選手raw3をAIが初期化時刻F38548の画像で指定した。指定設計は `../identity_diagnosis/seed_design.json` に修正経路の作成前に保存した。元の確認区間F38541〜38548でもraw3の検出がある。人手の本人同定正解や自動初期化の改善成功ではない。

初期化後の全653フレームに存在するraw3の検出枠をN1へ結び付けた。検出枠を新造・補間せず、元の7フレームの初期化待ちも埋めない。N2の653観測を保持し、初期の選外人物の外観集合と手前の重なり除外が変わるため、奥の探索は同じ数値設定で再計算した。奥の1291観測は元と同一だった。

固定入力F38846〜38906の31時点は変更していない。修正版の全31時点で、N1は手前右の濃色帽子・白赤、N2は手前左の白帽子・白赤、F1は奥の黒、F2は奥の橙色に対応して見える。全31時点に4候補があるが、AI画像点検は独立した本人同定・位置精度評価ではない。奥F1のF39145〜39159の欠測を保持した。

元の誤割当で指定末尾の手前横間隔は画像幅の0.584、修正版では0.292。誤った審判の位置は、このままでは配置と得点側の分析を歪める。修正後の値も検出枠下端からの近似であり、足接地点の正解ではない。

`AI_visual_findings.json` は元自動出力の失敗記録も継承する。`candidate_availability` と `inspected_images` は元出力の点検を指し、修正版の判断は `observation`・`AI_requested_identity_images`・`known_wrong_person_assignment=false` に記録した。フィールドの対象を明確にする補足を `AI_visual_findings_addendum.json` に保存した。

`service_prefix_review_h264.mp4` はF38662〜39200、539フレーム・約9秒、1920×1080。AI-assistedの表示を付け、元の縦横比を保持した。末尾には放送切替を含み、正式な得点確定フレームの正解ではない。映像点検用であり、代表性のある精度評価用の抽出ではない。

修正版2597枠の元検出との一致、配置値379個の別実装再計算、660フレームの動画を検査した。追加公開検査では旧入力の保持、539フレームの抜粋、元の既知誤出力が入力へ入る前に拒否されること等を検査する。得点側は未確認のままで、今回の個別指定やAIの得点表示候補を人手正解へ昇格しない。
