これは正確な接触1フレームやサービス有効性の独立正解ではない。低い打点のサーブという打法もAI所見。サーブ側の候補は手前・左、試行番号は不明のままとした。新しい記録は `cohort_anchor_proposals/008/contact_proposal.json` にあり、画像・旧候補・AI所見の由来を保持した。
