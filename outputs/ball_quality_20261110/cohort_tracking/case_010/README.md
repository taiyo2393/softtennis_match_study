## 欠測の診断

F23770・23772・23774・23776でF1が欠測。しかし元の検出raw41は全てに存在する。`input_gap_detail.jpg` では橙の選手が見えている。`input_gap_prefilter_diagnosis.json` で元の選別条件を再現すると、位置範囲、手前選手との重複、通常の外観距離は全て通過し、「初期選手以外の外観に近い候補を除外する条件」だけで除外されている。

これは検出器が人物を出せなかった例とは区別する。初期化F23533は映像のディゾルブ中にあり、初期外観の品質にも懸念が残るが、それが除外の原因だったとは確定していない。今回の1例だけで閾値を変更せず、元出力・固定時刻・4欠測を維持した。比較条件を変更するなら複数候補で既知の別人追跡も含む対照実験が必要。

奥の2人の長い途切れ各2箇所も、縦横比を保った拡大画像で点検した。示した前後では同じ服装の選手への対応と整合するが、全フレームの正解を付けたわけではない。部分枠・跳躍中の枠下端は地面上の位置として偏る。遮蔽箇所への座標補間は加えていない。
