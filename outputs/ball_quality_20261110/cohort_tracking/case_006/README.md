# 固定標本006：初期化待ちを含む追跡結果

001・004と同じ数値設定で006を処理した。既存の人手得点側「奥」を再利用した。入力を作成できたが、**指定31時点のうち、4人分の採用済み観測があるのは後半11時点だけ**。これは可用性の結果で、本人同定・位置精度ではない。

## 固定入力と初期化の遅れ

既存のAI接触候補F10495〜10506を使い、F10536〜10596を2フレーム間隔で要求した。約175.776〜176.777秒の窓。サーブ接触候補末尾+30からの規則を維持した。

4人の初期化はF10575で、確認に使った8ソースフレームはF10568〜10575。先頭20要求時点F10536〜10574には、どの選手スロットの出力もない。後半11時点F10576〜10596には4人分がある。

初期化待ちの20時点すべてで、後にN1/N2へ割り当てたraw ID2/1の人物検出は存在した。画像上でも手前2人が見える。つまり、0/4という出力を「4人がいない」「全員の人物検出に失敗した」とは解釈しない。4人同時に8フレーム分を確認する結合した初期化処理が、手前ペアの出力開始も遅らせている。raw IDの検出があること自体は本人同定の独立正解ではない。

`prefix_missingness_reasons.csv` と `gap_diagnostics/initialization_diagnosis.json` に、単なる未出力ではなく初期化待ちと分かる形で保存した。指定窓を初期化後へ動かさず、前半の座標を遡って補っていない。

1時点版の指定末尾F10596は4人分がある。区間平均は後半の11観測時点、約0.334秒の範囲だけを材料にし、両ペアの観測率11/31を付けた。完全に観測された1秒の軌跡の平均とは同一視しない。元の区間要約の開始から終了への変化量は、開始が欠測のため両ペアとも空欄。今回を見て除外閾値を新設して候補を外すことはしていない。

## プレー中かの点検

原画像の前後の時間順画像列と、全31要求時点をAIが点検した。手前左のサーブ後、奥側の受球動作、手前左の次の打球準備、さらにその後の応酬が続く。入力がプレー中にあるという解釈と整合し、明らかな待機・終了後の混入は点検画像では見られない。正確な接触時刻、有効サービス、得点成立フレームを今回新たな人手正解として確定したわけではない。

元候補の文脈F10370〜12497を2128フレーム処理した。待機や後のディゾルブを含みうる範囲で、全区間の4枠観測1447/2128をラリー全体の成功率には使わない。F12497は次の映像へのディゾルブを含み、得点成立時刻の代わりにしない。この終盤画像は今回の序盤特徴には入らない。元の追跡経路探索は未来のフレームも使うオフライン処理である。

## 見失いと再取得の画像点検

最終経路の初期化後の途切れは、N1が0区間、N2が3区間、F1が12区間、F2が29区間。各スロットの長い途切れ上位2区間、計6区間を、結果を見る前に決めた規則で画像化し、AIが点検した。これは難しい箇所の診断用選択で、全体の本人同定精度を測る標本ではない。

N2の65・52フレームの途切れは画面端から出て戻る動作と整合した。F1の24・18フレーム、F2の35・28フレームの途切れでは、手前選手との画像上の重なりが見える。点検画像の前後では衣服や位置関係と割当てが整合し、明らかな相方との交換は見られない。ただし固有の本人を独立に確定したものではなく、画像間の全フレームも保証しない。

特にF2の遮蔽後やN2の画面端では、頭・上半身・端で切れた部分枠が採用される場合がある。本人対応が整合しても、枠下端が足元を正しく表す保証はない。全ラリーの位置精度の課題として残す。数値閾値の変更や、部分枠を接地点の正解にする処理は行っていない。

raw IDの切替はN2が3回、F1が22回、F2が57回。これは全画面・拡大検出のID番号の切替であり、実際の選手IDの交換回数ではない。stage4の中間出力の再取得イベントを、最終の奥ペア経路の正解数や交換回数として数えていない。診断は最終CSVから行った。
