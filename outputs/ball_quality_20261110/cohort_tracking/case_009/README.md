# 009：自動出力の人物誤選択と、別保存した修正版

**このフォルダ直下の自動出力は、N2に選手以外の人物を含むため、配置の分析入力として不採用。** 元出力は残し、比較用入力へは `AI_seed_binding/` の修正版を採用した。修正版にはAIによる選手指定が入り、完全自動の成功例とは数えない。

## 自動出力で見つかった誤り

同じ数値設定でF21039〜22147、1109フレームを処理した。初期化F21101でN2へ入ったraw ID8の枠は、元4K画像でx約0〜104、下端y約1371。画面左端の非競技者で、in_initial_roi=0。後に同じ場所のraw423へ継続した。実際の手前右のサーバーraw148には、N2が付かなかった。

元の自動出力は同一時点のスロット重複なし、元検出枠との座標一致、特徴量計算一致の検査に通っていた。指定窓では16/31時点に4枠があったが、人物が正しく4選手かどうかは別問題だった。画像点検で誤りを特定し、`AI_visual_findings.json` にknown_wrong_person_assignment=trueを記録した。数値の整合性合格を本人同定精度と読み替えない具体例である。

## 修正

既存の点検時点F21855（名目接触−30）で、実際のサーバーに対応するraw148をAIが指定した。このIDの元の検出枠はF21848〜22147の300フレームで途切れずに存在する。修正対象をN2だけに限定し、この範囲で観測済みのraw148を結び付けた。座標を推測したり、欠測へ補間を入れたりしていない。N1・F1・F2の観測と固定入力時刻はそのまま。

修正版を `AI_seed_binding/` に保存。AIが修正画像F21855・21885・21915・21945・21975・22130を点検し、N2が実際のサーバーを指すことと整合した。独立の人手本人正解や、汎用の自動初期化改善を達成した結果ではない。

修正前後とも4枠がある要求時点数は16/31で変わらない。修正後は枠の数ではなく、N2に対応する人物と配置値が変わった。指定末尾の手前重心xは画像幅比約0.213から約0.650へ変わる。これは誤った人物が配置へ与える影響の例で、独立な位置誤差の改善量ではない。

元の自動出力は3677観測・379値・動画2218フレーム等の整合性検査を保持。修正版では元の検出枠と1025観測の一致、うちN2の300観測の明示的な差し替え、他3人の725観測の完全保持、379値の別実装再計算、300動画フレームの全デコードを確認した。
