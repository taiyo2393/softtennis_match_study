## 使用範囲と次の検証

手前側の追加案は各時刻までの観測だけを使うが、4人追跡の奥側は後続映像を使う。システム全体をオンライン予測処理と呼ばない。009の非競技者での初期化は今回の変更対象外で、別の対策が必要。

相手外観を追加した効果は、この比較だけでは分離できていない。外観特徴は色ヒストグラムで、学習済み本人識別器ではない。同じ試合の既に見た区間で変更を設計したため、汎化性能の主張はできない。追加案は実験用に保存し、正規の15候補入力・AI指定の修正版・11件の得点側正解は保持した。
