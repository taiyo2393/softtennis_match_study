- `human_outcomes.csv`: 互換性を保った12候補の結果台帳。008の得点側・確認IDは空欄。
- `confirmed_human_outcomes.csv`: 人手確認済みの既存11件だけ。以前の11件と内容が一致する。

`feature_schema.json` の学習用ラベル参照は `confirmed_human_outcomes.csv`。将来の教師あり評価では確認済みラベルとIDで結び、未確認の勝者を0・手前・奥などで埋めない。ラベルがない008も、固定標本と追跡整備の分母には残す。既存のスコア機械提案を人手正解の代わりにしない。
