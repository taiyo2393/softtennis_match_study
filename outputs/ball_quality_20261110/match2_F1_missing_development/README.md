# match2：F1欠測4フレームの原因調査と遠方切り出しの開発試験

## 結論

新画角のコート校正に合わせた遠方切り出しを追加すると、固定区間003のF1欠測4フレーム（54328・54330・54538・54544）に実検出枠を追加できた。既存3696観測の選手枠・スロット・raw IDはすべて維持した。補間、選手IDの手指定、閾値緩和は行っていない。

ただし、54538・54544の追加枠は上半身までで、下端は足元ではない。**人物候補の再取得であり、足元位置の復元を達成したとは扱わない。** 4枠ともAIの画像確認のみで、独立した本人同定精度・位置精度は未評価。既知の失敗を見てから実施した開発試験であり、独立テストの成功率ではない。

## 比較条件

- 元の固定15秒区間002・003を保持。カメラ切替を含む全1798フレームの追跡再生を保持し、コート線が支持された303＋636＝939フレームに両方の切り出しを適用した。既知の4枚だけを検出し直した比較ではない。
- 対照は全画面検出のみ、旧画角の遠方ROI、新校正へ移した遠方ROIの3条件。旧ROIも失敗結果として保存した。
- 新ROIは新旧校正の奥ベースライン・ネット地上線に対する画像幅・高さ比の余白から一度だけ算出。対象選手の枠・対象フレームの座標は使わず、ROIの探索は行っていない。人体の3次元投影を保証する方法ではない。
- 検出器は既存YOLO11m＋ByteTrack。信頼度0.25、入力1280、初期化8フレーム、既存の動き・外観・サイズ・カメラ領域・重複除外を維持。元1080pを正規座標4Kへ変換する処理は解像情報を増やさない。
- 対象2区間には各1つの連続したコート線支持区間しかない。複数カメラ区間へ一般化する際には切り出し側ByteTrackのリセットも設計し直す必要がある。
- 固定区間001は従来どおりプレー前除外を保持。ラリー開始・終了・得点側の未確定状態も変更していない。

分母には初期化待ち7フレームを含む。これは**出力の有無**であり、本人同定の正解率ではない。新ROIでは1856枠が候補プールに加わり、追加で選択された観測は4件のみ。1856枠を正しい人物検出件数として数えない。既存選択枠は同一だが、候補追加によって代替割当との差などの内部スコアまで全件同一とは主張しない。

## 原因の切り分け

元の候補列では、4枚とも直前のF1に対応するraw IDの枠がない。54328・54330ではF2の枠がF1にも有限コストとなるが、1対1割当によってF2に保持される。54538・54544では有効なF1候補自体が残らない。割当条件を緩めて別人で埋める方針は採らない。

追跡前の全画面YOLOを同じ画像で再実行した診断では、54328・54330・54544に新しいF1枠と重なる匿名枠がある。54538には対応する枠が見当たらない。前3枚は追跡段階で候補から外れた可能性、残り1枚は全画面検出の取り逃しが示唆される。内部状態を記録した同一推論のトレースではないため、原因を確定したとはしない。匿名枠に永続IDを与えて追跡へ混ぜてはいない。

前回のAI所見「4枚とも手前N1との重なり」は誤っていた。原画像の拡大では、最初の2枚は奥F2、後の2枚は手前N1との重なりだった。訂正は別JSONに保存し、既存の報告・ハッシュは変更していない。

## 採用判断と次の課題

新ROIは追加候補生成の開発案として保持する。元の追跡結果、現在の22区間の入力、本人・球・ラリー・得点側ラベルは上書きしない。上半身枠の下端をそのままコートへ写した座標で、選手配置や速度を分析する段階には進めない。

次に検証するのは、未使用区間での本人取り違え・余計な候補の増加と、足元を取得できない場合に座標を欠測として残せること。今回の4枚を繰り返し調整して精度を算出しない。位置の推定・補間を導入する場合は、観測座標と別列に保存し、独立した位置参照で評価する。

実装上、インストール済みByteTrackのIDカウンタはモデル間で共有される。今回の初期フレームの採番上限は旧ROI8/9、新ROI11で、以後persist=Trueによりリセットされず、各モデル内でIDの再利用は生じないことを確認した。今後の複数モデル実装ではカウンタを隔離するか別パスに分ける。
