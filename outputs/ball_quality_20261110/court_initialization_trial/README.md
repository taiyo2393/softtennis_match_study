# 初期人物選択：既存コート校正で審判等を候補から外す試作

015では、信頼度上位の人物を選ぶ初期化で審判が混入し、4候補が存在しても手前ペアの横間隔が大きく歪んだ。009でも画像左端の非選手を初期化に使っていた。この既知の2失敗を開発事例として、既存のコート校正を与えた条件で、個別の選手IDを指定せずに初期人物を選び直す処理を試した。

元の検出枠下端を既存ホモグラフィでコート平面に写し、幅方向−0.15〜1.15、長さ方向−0.25〜1.25の拡張領域に入る候補だけを初期選択に使う。コート外に立つサーバー等を落とさないため余白を持たせたが、これは開発用の工学的な設定値であり、測定誤差から推定した許容範囲ではない。数値探索や結果を見た閾値の調整はしていない。

変更は初期化前だけ。従来の8フレーム確認・重なり検査・検出閾値・追跡条件は維持し、初期化後の移動にこの領域制限をかけない。候補が不足すると待ち、非選手や推定座標で4枠を埋めない。コードに区間別の人物ID・服装・得点側を埋め込んでいない。既存校正と区間・接触情報という入力が必要であり、カメラ校正まで自動化した処理ではない。
