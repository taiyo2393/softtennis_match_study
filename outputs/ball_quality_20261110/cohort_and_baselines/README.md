# 次の標本と比較条件（2026-11-10）

研究テーマの最終決定は保留したまま、選手・球の整備結果を研究に使えるようにするための技術用標本と比較条件を固定した。現在の8候補だけで予測モデルや配置の優劣を評価する段階ではない。

## 比較したいこと

問いは「サーブ側などの基本情報に、同じ序盤区間の配置を加えると、得点側を説明・予測する情報が増えるか」。この比較ができれば、配置をわざわざ測る実用上の価値を評価できる。関連や予測が得られても失点の原因とは扱わない。

|比較|利用する情報|目的|
|---|---|---|
|B0|学習側だけで求めた得点側の偏り|全件を多い側とする程度の結果との比較|
|B1|B0とサーブ側|サーブ権に伴う基本的な違いとの比較|
|B2|同じ基本情報と固定時間窓の選手配置|配置を測る追加価値の確認|
|B3|B2と同じラリー・同じ時間窓の球情報|球を測る追加価値の確認|
|診断|基本情報と欠測フラグだけ|配置ではなく追跡の欠け方を学習していないかの点検|

現在再利用できる基本属性は、既存11件に付いた**AI候補のサーブ側**。`basic_server_inputs_current8.csv` には既存8候補のサーブ側だけを別入力として作った。人手の独立確認済みとは扱わず、由来を `basic_covariate_provenance.csv` に残した。古い配置の値や勝者との差は取り込んでいない。

サーブ位置の左右、1st/2nd、得点前のスコア、得点前に決まるチーム対応は、今後の基礎条件として重要だが今回は空欄のままにした。試合開始やゲーム切替直後の古い表示、サーブのやり直しに注意する。勝者チーム名から入力用チーム属性を逆算しない。サーブ側の有無だけで交絡を調整できたとは言わない。

球を整備した044・056は両方手前得点で、B3の有効性比較にはまだ使えない。B2とB3を異なるラリー集合で比べると、球の追加効果と標本の違いが混ざる。将来は共通の対象・時間窓・分割で比較する。

## 見えやすい標本だけに絞らない理由

既存の人手得点側11候補と、AI候補のサーブ側を対応させると、サーブ側得点は7件。以前の「4人分の単一時点の概算配置がそろう9件」に絞ると、同じ7件が残り、遮蔽で外れた005・006はどちらもサーブ側の失点例だった。これは選択によって標本構成が変わる具体例であり、サーブの得点率や追跡誤差の推定ではない。

現在の連続選手出力8候補では、サーブ側得点5件・相手側得点3件。これも便宜標本と暫定属性による構成の記述で、分類器の精度や母集団の得点確率ではない。005は既存8候補に含まれ、欠測を残して処理されている。

## 次の30候補群

元の63候補を既存のポイント群表へ対応づけ、時刻順の最初の30群を技術的な成立性の確認対象に固定した。今回は001〜030に対応する。050/051は同一点という既存の人手回答を保持し、全体では63候補・62暫定群。先頭30の外にあっても統合は維持する。

選択には時刻・候補ID・既存群IDだけを使った。得点側、追跡の見栄え、元の除外状態、サーブ接触の整備済み／未整備は選択に使わない。これらの値と入力順を変えても対象・順番が同じになる検査を通した。未確認の複数ポイント分割が後で判明したら、群の対応を版管理して更新する。

固定時点の選手特徴が既にあるのはこの中の5候補（002・003・005・007・025）。人手の得点側があるのは8候補。固定時点の特徴がない25候補を時刻順で処理し、最初は001、その後004・006・008…とする。これは作業の再利用であり、未処理候補や失敗例を標本から除くことではない。進捗は固定した名簿と分けて記録する。

欠測・ダブルフォルト・サーブ不明・編集・ラベル不明・追跡失敗があっても、別の良いラリーへ入れ替えない。得点ラベルがある／指定窓が整う／追跡観測がある／独立に精度が分かるという段階を分け、全30候補群の処理結果を残す。30群を30件の完全な独立ラリーと呼ばない。

044・048・056はこの30群の外にある既存の開発例として別に保持する。30群の件数を増やすために都合よく足し込まない。以前に固定したスコア候補の16件の検証標本も変更しない。標本の目的が異なるので、今回の名簿で置き換えない。

## いつ評価するか

この試合は長期間の開発・確認に使っているため、新しい未見の評価試合とは扱えない。30群は処理の成立性と失敗要因を調べる予備標本で、十分な統計的検出力を保証する数ではない。現時点ではモデルを学習・比較しない。

将来は別試合を、得点や追跡結果を見る前に対象として固定する。試合と同一ポイント群をまたがせず分割し、欠測処理・正規化・モデル選択も学習側だけで行う。必要な試合数・ラリー数は、追跡誤差・欠測・試合間のばらつきと目的の差を見て見積もる。「30〜50あれば本評価になる」とは決めない。画像上の概算配置の測定誤差が、比較したい差に対して十分小さいかも別途評価する。
