# 白い手袋への誤検出対策：実験版 v1

この試合向けの試作として、検出候補が青い上着の人物の上げた手首に近い場合、座標の出力を保留する処理を実装した。
白手袋への誤検出の一部を抑えられたが、正式な採用版への置き換えは行っていない。
元のモデル出力・正解注釈・比較結果は保持している。

## 手法

1. 現行版が検出した候補の周囲384×384を切り出し、既存のYOLO11m-poseを960サイズで実行する。
2. 肩・腰4点の信頼度が0.4以上の胴体ポリゴンにおける青色画素の割合を測る。
3. 青色割合0.5以上、手首信頼度0.6以上、肩信頼度0.5以上で、手首が対応する肩の高さ付近か上にある場合を対象とする。
4. 候補と手首の距離が人物の高さの0.12倍以内なら、候補を `withheld_uncertain` として保留する。

距離の下限候補0（処理なし）、0.08、0.12、0.16を検証用データだけで比較し、正しい位置を一つも失わず誤出力を最も減らす設定を選択した。
テストへの適用前に0.12に固定した。テスト結果を見た変更は行っていない。
真のボール位置を補間・推定して追加する処理ではない。保留した座標もraw列に残す。
可視と判定したまま不明瞭な座標を渡す代わりに欠落として扱うため、欠落への耐性がある下流処理が必要。

## 既存注釈に対する比較

| 指標 | 現行版 | 実験版 |
|---|---:|---:|
| 検証：16px以内の位置正解数 | 80/121 | 80/121 |
| 検証：誤出力数（誤位置＋非可視時出力） | 9 | 8 |
| テスト：16px以内の位置正解数 | 96/128 | 96/128 |
| テスト：位置再現率 | 75.0% | 75.0% |
| テスト：誤位置数 | 3 | 2 |
| テスト：非可視注釈への出力数 | 1 | 1 |
| テスト：位置正解数／座標出力数 | 96/100 | 96/99 |
| テスト：可視注釈時の未検出・保留数 | 29 | 30 |

検証では006の899フレーム、テストでは018の216フレームを保留した。
可視注釈のある標本で誤った座標を欠落に変えるので、位置正解数は変わらず、可視検出だけの再現率は下がる。
誤った座標を消す改善と、ボールを再発見する改善を区別する。
テストは既に何度も見ている同一試合内の開発用比較である。この数値を未知の試合への汎化性能として主張できない。

## 連続映像の出力

013の450フレームと018の240フレーム、合計690フレームに同じ設定を適用した。
013で6フレーム、018で7フレームを保留した。これら13フレーム全てを等倍切り出しでAIが点検し、いずれも線審の手袋付近の候補だった。
独立した全フレームの正解照合ではないため、「13件の精度改善」や「連続区間の誤検出ゼロ」とは扱わない。

## 残る問題

- 013の435フレームは、姿勢推定が実際には上がっている腕を下げた姿勢として出し、白手袋を保留できなかった。前後の434・436–440では保留できており、判定が一時的に途切れる。
- 青い上着という、この試合の線審の服装に依存する条件である。別の服装・チーム・大会への転用は未検証。
- 本物の球が上げた手首付近を通過した場合、誤って保留する可能性がある。人物領域全体を消す処理ではないが、危険が無くなったわけではない。
- 手首を取得できない場合は元の候補を残す。姿勢推定の欠落をボールの非可視と同一視しない。
- ラリー途中のボールのブレ・遮蔽による未検出は、今回の処理では回復しない。

## プレー中・準備中の評価の整理

成功例も含む全300標本を `context_inventory.csv` にまとめ、追跡成否とは無関係に既存注記だけで場面区分の手掛かりを付与した。
サーブ前の注記40件、ラリー後の注記2件、それ以外258件である。注記のない258件を自動的にプレー中にはしていない。
これらは場面区分の正解ラベルではなく、既存注記からの候補である。
カメラがコートに戻った時刻をサーブ接触時刻と同一視せず、既存の広い候補区間だけから全300件の場面を確定しない。

また検証用の002・244フレームは `not_visible` だが「ボールが二つ見える」という注記があり、002・1420フレームにも球らしい移動像が見える。
実際に追跡すべき球が見えない状態と、複数球のため対象が定まらない状態が区別されているか不明である。
元の可視性や座標を自動修正せず、ラベル定義の確認候補として記録する。

今後の区分では、対象球（そのポイントで使われる球）を明示し、準備中・各サーブ試行・プレー中・終了後・対象不明を分ける。
ファーストサーブのフォルトとセカンドサーブは同じポイント内の別サーブ試行として扱い、ファーストフォルトだけで得点ラベルを付けない。
場面別の精度は、失敗標本だけを除外して計算せず、成功例を含む全標本を一貫した規則で区分してから評価する。
