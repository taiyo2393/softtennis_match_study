# 時系列の基準に使われた軌跡の確認

固定済みの局所直線モデルの選択をそのまま再計算し、どの検出点を基準にしていたかを保存した。
アルゴリズムや閾値を変更して有利な結果へ作り直したものではない。

- **002・318**：基準は約(1292,772)にある別の実球。20点・速度約2.01px/frameで支持される。ユーザーが確認した(558,680)の球とは別の選手の球だった。
- **014・626/630**：基準は約(1260,539)の線審の頭付近への検出。6点・速度約0.19px/frame。本物の手元の球を、この別物と比較して除外していた。
- **018・208**：基準は約(752,581)を通る移動中の球の候補。10点・速度約1.09px/frame。手への飛び移りを約368pxの逸脱として判定できた。

002では基準も本物の球なので、速度や移動量だけを厳しくしても球の同一性は決まらない。
静止した基準だけを禁止する対策も、002の反例には効かない。
基準が同じ対象球を追っていることを確認する前に、検出数の多さで他の観測を消すことが問題だった。

`reference_reports.json` に選択されたモデルの点対、支持する全時刻・座標、予測位置・速度・残差を記録した。
各 `*_reference.jpg` の水色は元の候補、オレンジは局所モデルの予測位置であり、オレンジをその時刻の実測検出とは扱わない。
下段は基準を支持した4時刻の元画像の等倍切り出し。
002の2球の候補を保持する次の試作は `../../../ball_quality_20261103/multiball_pilot_002/README.md` を参照。
