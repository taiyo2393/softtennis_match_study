# 連続軌跡の途中でF1/F2を交換しない探索（2026-11-02）

第6段階の002で、同じ元ID5の連続した枠が途中からF2へ割り当てられ、逆方向では
開始時のF1/F2が反転する不安定さが出た。この問題に対する開発版。
旧版・元検出・動画・人手確認記録は保持した。

## 変更

元の検出IDを、時間的な欠落、足元位置の急な飛び、箱サイズの急変で短い軌跡に分割する。
8観測以上ある軌跡については、1つの経路仮説内で途中から別選手へ渡すことを禁止した。
開始時の人物に対応する軌跡も固定する。
検出ID全体を無条件に同一人物として固定する方式ではない。

8観測はソースフレーム数で、独立した8枚の動作観測ではない。
元検出器が接近・交差時に滑らかにIDを交換した場合は、この分割規則でも見抜けない。
連続性制約の成立を、人物同定の正解とは扱わない。

探索のビーム幅、位置・速度・服のコストなどは第6段階から維持し、新しい制約を
同じ設定で002・005・048に適用した。各実行の前に設定・コードハッシュを保存した。

## 検証結果

| 区間 | 逆方向から開始時へ戻した対応 | 第6段階との差 |
|---|---|---|
| 002 | F1→元ID5、F2→元ID4で一致 | 前版の方向間反転が解消。元ID5の同一連続軌跡を途中でF2へ渡さない |
| 005 | F1→元ID22、F2→元ID3で一致 | 新版の提示動画をユーザーが確認済み |
| 048 | F1→元ID5、F2→元ID2で一致 | 確認済み第6段階の全1351観測と、人物ラベル・元ID・座標が完全一致 |

両方向で同じ人物ラベルが付いた箱の比較は、002で561/561、005で609/609、048で1334/1334。
これは連続フレームの方向間一致であり、独立した本人正解に対する精度ではない。
逆方向の起点も順方向の候補から作っている。
002の更新動画は、その後ユーザーから「合ってる」と確認された。
`players_002_global/human_video_review.json`に、提示動画単位の本人対応確認として記録した。
これは独立した全フレーム正解の付与ではない。005もその後、動画内で同じ選手を追えているかという質問に
ユーザーが「合っている」と回答した。`players_005_global/human_video_review.json`に動画単位の確認として保存した。
048は新たに人手評価したのではなく、確認済み経路との出力同一性を検査した。

全座標はそのフレームの検出枠に対応。欠落中は内部の位置予測を使うが、補間座標を出力しない。
手前側は従来の候補を再利用しており、今回の変更で改善したものではない。
対象は同じ試合内の既に検討した区間であり、未使用試合の汎化評価ではない。
