# 小規模な位置代表点の比較

入力：position_reference_review.html。画像を埋め込んだ単独HTMLで、ダブルクリックして通常のブラウザで開ける。サーバーは不要。アプリ内ブラウザのlocalhost接続はタイムアウトしたため、画面の実表示による検証は未完了。

4人分の候補がある9件を候補番号順に並べ、その先頭・中央・末尾（001・007・056）を選んだ。12選手の左右の靴の下端中央を人手で指定。判断できない場合は空欄を推測で埋めず、判別不能とする。AI点は入力画面に表示しないが、この確認者は過去に候補画像を見ているため厳密な盲検独立評価とは呼ばない。

この比較は箱下端代表点と手動画像代表点の差を測るもので、物理的な地上位置誤差・校正精度・追跡ID精度をまとめて評価するものではない。056で浮いている選手も画像点は指定できる場合があるが、地面上の接地点に読み替えない。

入力結果はmanual_position_reference.jsonとして保存される。途中経過は当該ブラウザのローカルストレージに保存。こちらが入力代行して人手正解を作成したことにはしない。別の確認者や再注釈による再現性の評価は今後の課題。
