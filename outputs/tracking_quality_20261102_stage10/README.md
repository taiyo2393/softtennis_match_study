# 025終盤の短い欠落をまたぐ本人対応の修正（2026-11-02）

## 原因の切り分け

025の順方向経路は、終盤まで元ID6をF1、元ID4をF2として追っていたが、
F60487以降に相方へ割り当てる接続が生じていた。
元ID4はF60478→60487で8フレーム、元ID6はF60486→60499で12フレーム、同じ元IDの観測が途切れる。
旧規則は端点間4フレームを超えると必ず別の軌跡に分割し、連続軌跡の人物対応を守る制約が切れていた。

欠落前後5観測から求めた前向き・後ろ向きの速度予測誤差は、箱高さ単位で
元ID4が約0.220/0.207、元ID6が約0.065/0.041だった。
同じ元IDだから無条件に接続するのではなく、前後の連続性を使う根拠がある区間として扱う。

## 変更

- 端点間30ソースフレーム以内の欠落を検討する。
- 前後それぞれ最大5観測、最低3観測を使う。各側にさらに長い欠落があればつながない。
- 箱高さ比0.6〜1.6、前後両方向の速度予測誤差が箱高さの0.75以内の場合のみ、
  同じ元IDの短い欠落を連続した軌跡として扱う。
- 急な位置・サイズの飛びと、長い欠落は従来どおり別軌跡へ分割する。

位置・服のコストやビーム幅等は第7段階から維持した。
接続は本人対応の制約に使い、欠落中の座標は補間・外挿して出力しない。
検出器自身が滑らかにIDを交換する場合はこの規則でも誤る可能性があり、元IDを正解とは扱わない。

## 025の結果

順方向と逆方向がともに開始時の元ID6→F1、元ID4→F2へ戻った。
両方向で観測した968組の対応枠は全てIoU>=0.5で一致した。
旧経路との比較では、出力968観測中921観測が同じ、47観測の割り当て・枠選択が変わった。
この一致は独立した本人正解に対する精度ではない。
その後、更新動画の提示に対してユーザーから「合ってる」と確認された。
同動画フォルダの `human_video_review.json`へ動画単位のF1/F2対応確認として記録した。
独立した全フレーム正解の付与や、欠落位置の正しさの確認とは扱わない。

## 確認済み区間との比較

同じ変更を002・003・005・007・048にも適用。
各区間の奥側の全人物ラベル・元ID・座標が確認済みの経路と一致することを検査した。
003は第9段階の修正済み手前候補を入力として使用した。
手前側は従来の観測を再利用し、今回の025の手前側の未出力は改善していない。
新しい区間や別試合への一般化精度は測っていない。
