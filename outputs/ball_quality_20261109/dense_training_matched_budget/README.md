# 追加注釈の効果：学習量を揃えた8クリップ除外比較

**この固定設定では改善せず、不採用。** 従来の68中心で学習した8モデルを対照とし、181中心を使う側も更新回数・各回のbatch size・入力総数を揃えた。評価クリップに属する旧・新規中心は全て学習から除外した。計6429更新、約385秒で比較を完了した。

モデルの全データ学習、新しい確認用区間への推論、別の識別器・閾値の試行、正規追跡の更新は実施しない。追加注釈を無効と判定したのではなく、**この学習予算・サンプリング・候補選択の組合せでは改善を示せない**という結果である。

条件の説明は `METHOD.md`、実行前の固定条件は `protocol.json`。

## 主集計：従来の同一時点

123時点のうち、人手でプレー中とした77時点（可視球68、観測不能9）を共通範囲とする。両方式とも、以前の全画面時系列方式に出力があればその座標を保持し、欠測時だけ9領域の実候補で補完する。

|学習データ|正解／可視68点|位置違い|可視球の欠測|観測不能9点への出力|
|---|---:|---:|---:|---:|
|従来68中心の対照|64|2|2|4|
|181中心の追加案|64|3|1|5|

対照の64正解は全て保持した。ただしpilot004/local266で欠測が47.51px離れた位置への出力に変わり、pilot010/local229で観測不能時の出力が1点増えた。欠測が減ったことを、正しい球の回復と数えてはいけない。以前の2位置違いも残る。

プレー前後46時点は `summary.csv` に分けて保存する。対象外での数字を主集計の改善へ加算しない。

## 候補生成と候補選択を分けた診断

第二集計では、人手中心から16px以内に候補がある時点は、対照・追加案ともに110／117だった。この数字は人手中心を参照した候補内上限で、自動精度ではない。対照の選択正解110に対し、追加案の選択正解は109。今回の追加学習では、集計上の候補中心到達数を増やせず、候補選択でも1点を失った。

local754では、追加案の球付近の候補は人手中心から2.83pxで存在した。球付近候補と、最終選択された174.03px離れた候補の最大応答は、保存されたAMP値で同じ0.662109375だった。固定の同点処理で面積240の離れた候補が、面積225の球付近候補より優先された。候補の出現だけで正しい最終出力を保証できない具体例である。

一方local720・722には、追加案の候補群に人手中心から16px以内の候補がない。local754の同点処理を変更するだけで全ての残りを解決できるとはいえない。この結果を見て別の候補順位や閾値は試していない。

観測不能時の出力は、中心が指定できない時点への出力として集計したもので、全てを別物体と独立確認した数ではない。人手中心から16pxを超えるという位置評価と、物体の意味的な同定を区別する。

## 検証と採否

`verification.json` は passed。

- 8組の対照で、従来123時点の候補辞書と補完出力を完全再現。
- 追加側8モデルの保持クリップ除外、入力画像ハッシュの分離を照合。
- 6429更新、各回のbatch size、固定乱数の全入力順、有限の損失・勾配を再確認。
- 各モデルの学習対象8テンソルは変化し、それ以外の重みと全BN値は元モデルと完全一致。
- 保存した4374ヒートマップの成分を復元し、候補と732出力、集計・時点別の変化を再計算。
- 元の人手注釈、対照モデル、確認用区間、正規参照の保護対象ハッシュは不変。

事前条件は、主集計で対照の64正解を全て保持、位置違い0、観測不能時出力1以下、かつ第二集計で正解の喪失や位置違い・観測不能時出力の増加がないこと。今回の結果は満たさない。`operational_decision.json` に不採用を記録する。

この実験は学習データの効果を、計算量を固定して検討した内部開発である。追加側はデータ数が多いため、同じ更新数でのデータ全体の巡回数は対照の3epochより少ない。長く学習しても改善しないことを証明したわけではない。追加データで学習中のクリップ配分も変わるため、注釈数だけ、あるいは時間方向の情報だけの純粋な効果ともいえない。

新規教師は既知の同一試合・4つの約1秒区間に集中している。手法設計には既知の失敗例を参照しており、今回の保持クリップ除外は直接の学習混入を防ぐが、全ての過去の方式選択を含む独立外部評価にはならない。
