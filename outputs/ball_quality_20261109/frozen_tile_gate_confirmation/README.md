# 単一の補完判定器を固定した4短区間での確認

2026-11-09。学習側で1個の判定器を固定し、その後に既存4短区間・52時点へ適用した。人が球中心を指定できた45時点では、現行33正解・12欠測から、補完付き40正解・5欠測へ改善した。位置違いは両方0で、人が球中心を観測できない4時点への出力も両方0だった。

ただし、今回の区間は以前の検出失敗診断でも参照しており、拡大入力という仮説の検討にも関係している。学習に使っていない区間による同一試合内の開発確認であって、未見の外部評価ではない。正規追跡への採用・書換えはしていない。

## 固定した手法と学習

元のTrackNet重み、全画面の時系列候補選択、検出閾値0.3を保持した。現行の出力がない時点だけ、960×540の固定9領域から得た候補を追加する。native入力と同じ画角を劣化させたdegraded入力からの10特徴で、採用スコア0.5以上のnative実成分中心を補う。補間点や手動中心の転記は行っていない。スコアは校正済み確率ではない。

学習は前段のクリップ別内部比較と同じ81例（16px以内76例・位置違い5例、8学習クリップ）だけ。準備中・終了後の学習例も従来どおり保持し、プレー区分で学習データを再選別していない。球中心を指定できない7候補は負例に変換せず学習から除外した。標準化、クラス均衡付きlogistic損失、L2係数1、CPU float64、LBFGS300、ゼロ初期値、閾値0.5を変更していない。

学習側の全81例で作った1個のモデルは、プレー中の可視球68点で59正解・9欠測、位置違い0、観測不能9点への出力1だった。現行の52正解・16欠測、位置違い0、観測不能時出力1に対して、事前に定めた確認条件を満たした。

前回の60正解はクリップごとに別の学習モデルを使う内部予測の値である。今回固定した単一モデルの学習側成績59正解と区別する。モデルの学習・選択に52時点の中心正解は使っていないが、52時点の従来の結果を以前に参照しているという開発上の制約は残る。

## 確認区間の結果

元画像1920×1080で手動中心から16px以内を正解とした。全52時点に予測を保存し、中心位置が判断できない3時点を両方式から共通に除外。中心を観測できない4時点は出力の有無として別に報告した。

可視球の16px以内正解率は73.3%→88.9%。4区間の正解率の単純平均は75.8%→89.8%。元の出力は、座標・有無・confidenceも含め全て保持した。

追加正解7件のうち6件は区間Bで、もう1件はA13。元の正解の喪失は0だった。区間Bの連続した正解標本の最長列は3→9点に伸びたが、2フレーム間隔の標本であり、全フレームの連続追跡保証ではない。隣接標本間の変位誤差も `confirmation_adjacent_pairs.csv` に保持している。

残る欠測はA07/local1064、B10–B13/local201・203・205・207。これらに合わせてスコアや領域を変更せず、現モデルの限界として保存した。

## 採否と研究上の評価

確認前の条件は、元の正解を失わず、追加正解を1件以上得て、位置違いと観測不能時点への出力をそれぞれ増やさないことだった。今回の固定候補はこの条件を満たした。

これは次の検証へ進む根拠になる。一方、正規運用への採用や、一般の試合で88.9%を達成したという結論にはしない。改善は主に1区間で、負例も学習側5例と少ない。4短区間はそれぞれ約0.4秒の標本範囲であり、長い軌跡、別物体への乗り換え、ラリー全体の完全追跡、別試合での汎化は未検証である。近い時点を独立とみなす有意差検定はしない。

次は固定モデルを保持したまま連続区間で欠測の長さと乗り換えを確認し、別試合へ評価範囲を広げる。既存の52時点を学習へ移したり、この結果から特徴・閾値を選び直したりしない。人がプレー範囲を与えた条件であり、自動ラリー開始・終了判定の精度とは分ける。

全画面の時系列選択は最大8フレーム先を参照し、medianもクリップ全体から作成している。オンライン・因果的な処理ではない。また、元のAMP推論の出力を厳密に再現するため、保存済みのバッチ構成を使った。任意のバッチ構成・連続実行で完全一致することを保証する実験ではない。

## 再現性と保護

`protocol.json` と実行スクリプトを、単一モデルの学習と新しい確認用推論の前に保存した。モデル・標準化・閾値・データ・コードのハッシュを固定し、学習、安全確認、推論、集計を別の段階で実行した。推論段階では中心正解を参照せず、全52出力を固定してから集計した。

学習と確認でサンプルID・4画像入力ハッシュが重ならず、median生成に使われるクリップ全体の時間範囲も120フレームの余裕を持って重ならないことを確認した。時刻はlegacy edited match1であり、再ダウンロード動画の時刻へ転用しない。

元84文脈の成分辞書の完全再現、936タイルマップの圧縮保存からの成分再構成、41候補の特徴・スコア、52最終出力の由来、104評価行、追加正解7・喪失0を検査した。最適化目的の勾配残差も確認した。元注釈、従来の集計、原重み、確認済みの人物・球追跡参照は変更していない。
