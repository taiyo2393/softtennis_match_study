## 測れたことと制限

056の入力は、元の固定TrackNetによる未修正出力。先行する不採用モデル・追加学習・別の閾値は使っていない。今回の時計は、その入力を人が点検・修正した作業分である。元動画・画像キャッシュの準備、モデル推論、説明・初期設定は含まない。

予測を表示した状態での点検なので、225採用を独立した検出正解とみなさず、334／376も位置可用数として扱う。手動修正も予測表示ありの条件で、独立GTとは分ける。一から全点を入力する対照の時間を測っていないため、時間短縮率は算出しない。
