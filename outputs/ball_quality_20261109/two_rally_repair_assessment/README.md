# 2例の半自動整備：手間と研究上の判断

044・056の2例を確定した。**小規模な候補区間を、人の点検・補完を含めて整備する経路は実行できた。自動追跡だけで十分という証拠は得ていない。** 新しい時間計測・確認の依頼はここで止める。

|区間|候補内部の映像長|入力の状態|捕捉作業時間|新規手動中心|点検後の位置可用数|
|---|---:|---|---:|---:|---:|
|044|約6.7秒|以前の修正・6手動中心を含む|約4分9秒|23|164 / 201時点|
|056|約12.6秒|元モデルの未修正出力|約11分23秒|109|334 / 376時点|

両例は同じ確認画面・時間定義を使うが、区間の長さ・映像の難しさ・先行修正が異なる。この時間差で方式の優劣を比較せず、2例の平均を一般的な整備時間と扱わない。人の判断を見た別の独立評価者による中心誤差も測っていない。

## 実際に必要だった作業

044は予測採用135、新しい中心23（欠測追加22・既存位置変更1）、観測不能37、既存中心再利用6。056は採用225、新しい中心109（欠測追加97・既存位置変更12）、観測不能42だった。元の出力があるのに観測不能とされたのは両例とも4時点で、別物体と独立確認された数ではない。

056では元の欠測135時点のうち97に、人が見える球の中心を入力できた。したがって、元モデルの未取得は実際の観測不能だけではなく、人手による追加作業を要する部分を相当数含む。この負担を出力率だけで隠さない。一方、入力109時点を全て元の誤検出と数えることも誤りである。

整備後も044に37、056に42の観測不能時点が残る。位置は補間せず、欠測マスクと由来を保存した。使える区間・特徴量は、この欠測を前提に選ぶ必要がある。

## 研究者としての判断

1. **今の検出器の小改変を続ける優先度は下げる。** 直前の固定比較は改善を示さず、今回の作業も検出器自体の改善実験ではない。元の重みを保持する。
2. **半自動整備は、限定した卒論用データを準備する経路として残す。** この2例では実行できたが、全試合を手軽に処理できるという判断はしない。とくに未修正056では約12.6秒の対象に109中心の入力と約11.4分を要した。
3. **追加の注釈を増やす前に、必要な入力を決める。** 研究の中心である4選手配置と得点側の関係に対し、どの時点・長さの位置系列を使うかを定める。球の全軌跡を全ラリーで必須とせず、球情報を足す便益を比較できる範囲へ絞る。
4. **正解・評価の用途を分ける。** 予測を見ながら整えた座標は、データ準備・開発の資料として由来付きで保持する。予測採用を独立した精度の正解に転用せず、本評価の独立性と4選手本人対応・得点側の確認は別に確保する。

この判断はテーマの有効性や新規性の検証完了を意味しない。戦術や失点理由の因果説明も、位置を整備できたことだけでは認定できない。

## 作業量の仮定計算

予算検討用の算術例として、**全てのラリーが今回の056と同じ作業負担**だと仮定すると、30ラリーで約5.7時間、50ラリーで約9.5時間となる。これは母集団から推定した必要時間ではない。区間長、遮蔽、予測の質、作業者で変わり、画像・モデル処理、4選手の修正、得点ラベル、独立評価などは別に必要になる。

この仮定では限定規模の整備を検討する余地はあるが、注釈の価値は研究の比較に必要かで判断する。作業を増やせば研究が進むとは扱わない。
