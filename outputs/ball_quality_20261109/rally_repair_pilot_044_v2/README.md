## 操作

1. 説明を読み、「計測を開始」を押す。必要に応じて前後動画を再生する。
2. 水色の予測が使える場合は「予測を採用」またはA/Enter。中心を直す場合は元画像をクリックし、Enterで保存する。
3. 球を観測できなければN、判断できなければU、プレー区間外ならX。見えない位置を推測して埋めない。
4. 離席は「休止」。画面を隠す・別アプリへ移る場合も自動休止する。再開は「計測を再開」。途中まで保存して続けられる。

画像が読込み途中、計測が休止中、採用する予測がない場合の採用は保存できない。キーの押しっぱなしによる連続保存も抑止する。以前の6手動中心は保持し、新たにクリックし直さない。通常表示・拡大・全画面に対応する。

## 回答の意味

水色の予測を表示して点検する、実作業の試験である。結果は以下を分けて保存する。

- `existing_manual_center`：以前の手動中心6点。
- `accept_prediction`：予測を見て明示的に採用した位置。独立した精密中心GTではない。
- `correct_center`：予測を表示した状態で、新たにクリックして修正した位置。
- `not_visible`：球中心を観測できない。物理的な球の不在ではない。
- `uncertain`：判断保留。位置を作らない。
- `nonplay`：プレー区間外と判断。境界全体へ自動伝播しない。

全てに由来を付け、予測の採用を「予測非表示の独立した正解」として学習・精度評価に流用しない。完了後は、採用数、修正数、観測不能・保留・対象外、残る欠測と今回の時間を区間単位で報告する。採用率を独立な検出精度に置き換えない。

## 時間の記録

明示的な開始・再開、休止、画面の非表示・フォーカス離脱、5秒ごとのheartbeat、保存をローカルサーバーへ送る。サーバーの単調増加時計で区間時間を記録する。時計の初期状態や、実対象への架空の操作時間をエージェントが作らない。

通信・操作記録の間隔が15秒を超える場合、計上は最大15秒に制限し、残りを未計測の間隔として別記して休止する。操作が約60秒なく、動画も停止していれば休止する。ブラウザー・プロセスの突然の終了は最後の未保存区間を失う可能性がある。再起動時は休止から始める。記録値は「この仕組みで捕捉した作業時間」であり、人間の注意を精密に測った時計ではない。記録された空白や中断を併記する。

説明・初期設定・過去の作業時間は対象外。計測開始後の動画視聴、画像読込み待ち、移動・保存操作は含む。この1区間から作業時間の一般値や人とAIの優劣を推定しない。
