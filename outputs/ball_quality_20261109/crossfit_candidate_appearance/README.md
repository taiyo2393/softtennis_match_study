# 固定画像特徴の追加比較（2026-11-09）

画像特徴を追加しても残った位置違い2点を除去できず、観測不能時の出力が増えた。この固定案は不採用。全データでの最終学習、新しい確認区間への推論、正規追跡の更新は実施しない。

## 比較条件

直前の `../crossfit_native_candidate_ranker/` の8組の検出器・1197候補行をそのまま使用した。各組で検出器の追加学習、候補識別器の学習と正規化から評価クリップを除外した。候補の座標、検出閾値、画像領域は変えていない。

従来の応答・形状等10特徴に、候補中心の元画像32×32画素から取得する固定ResNet18の512特徴を連結した。ImageNet1K_V1重みは既存キャッシュを読み込み、重み・BNを固定した。RGB変換後に既定の256リサイズ・224中央切出し・正規化を適用する。拡大処理で元画像の細部が増えるわけではない。正解中心を使った切出しは行わない。

候補識別器は従来と同じフレーム等重みの正規化、フレーム内クラス均等重みの二値交差エントロピー、L2係数、LBFGSの設定、採用閾値0.5を使用した。既存出力を保持し、欠測時だけ同じ時点の実候補で補完する。座標補間はしない。正例は手動中心から16px以内、負例はその対象位置から外れる候補であり、一般的な「非ボール」分類の教師ではない。

比較案はこの連結1案に固定し、結果を見て画像寸法、モデル、特徴数、閾値を選び直していない。旧36候補の画像分類実験とは対象・分割が異なる。旧A〜Dの52時点とE/Fの26時点は今回の学習に使っていない。

## 検証と解釈

`verification.json` は passed。元画像から1197切出しを復元してハッシュ照合し、重複除外した539領域の画像特徴を再計算して完全一致を確認した。8識別器の学習対象・正規化、1197候補スコア、123保持側出力、集計と変更1点を照合した。既存検出器・注釈・正規参照の保護対象ハッシュは不変。

これは既知の同一試合に対する内部開発結果である。今回の直接の学習除外は守られているが、過去の方式選択を含めた全履歴が完全に入れ子の評価になっているわけではない。フレームを独立標本とした有意差や未見試合への性能を主張しない。特徴内容と次元数の両方が変わる比較なので、事前学習単独の効果も分離できない。

結論は「この固定した画像特徴追加で改善を確認できない」であり、「画像情報やAIが一般に無効」ではない。次に検討するなら、同じ少数の失敗点への閾値調整を繰り返すより、プレー中の連続した教師データと失敗条件の整理を先に進め、比較方法を固定して別区間で判断する必要がある。今回の結果だけで追加学習モデルを採用しない。
