# 拡大入力に合わせた球中心の追加学習：学習側で不採用

2026-11-09。候補の有無を確認したところ、未取得の多くは現在の候補の中に正しい中心自体がなかった。候補生成を改善できるかを調べるため、学習側のプレー中・可視球68時点だけで拡大入力への追加学習を行った。

**中心の取得は増えたが、誤った位置と観測不能時点への出力も増えたため、不採用とした。** 学習側の事前条件に違反した段階で止め、旧52時点・E/F26時点・他の評価側への新しい推論を行っていない。

## 比較

全方式で同じ学習側77プレー時点を使用。68時点は人手中心あり、別の9時点は中心を観測できないという既存回答である。正解は元画像で中心誤差16px以内。

| 方式 | 可視球68点の正解 | 位置違い | 可視球欠測 | 観測不能9時点への出力 |
|---|---:|---:|---:|---:|
| 元の時系列方式 | 52 | 0 | 16 | 1 |
| 前段の固定画像補完案 | 59 | 0 | 9 | 1 |
| 今回の追加学習モデルによる欠測補完 | 64 | 2 | 2 | 3 |

前段の59正解は全て保持し、5件の可視球欠測を正しい位置に変えた。その内訳は、元の候補が全くなかった4時点で新たに正しい中心を生成した例と、元から正しい拡大候補があった1時点を選べるようになった例である。いずれも学習に使った時点での結果で、未知動画の改善ではない。

新たな候補を得た4点はpilot001/local272、004/local238、006/local651、010/local137で、選択中心の誤差は約1.4〜3.2pxだった。旧候補を選べるようになった1点は001/local400、誤差約6.1px。境界を少し跨いだ変化を、新しい球候補の生成と混同していない。

一方、001/local368は手動中心から約674.9px離れた位置、007/local608は約61.7px離れた位置を追加した。可視球に対するこの2点は位置違いである。003/local377と010/local873では、既存の観測不能回答に対して新たに出力した。後者2点を物理的な球不在や別物体と新たに断定していないが、事前条件の出力抑制には違反した。

## 候補生成と最終選択を区別する

正解中心を使って全拡大候補を探した上限は、元モデル60/68→追加学習後64/68。これは候補の中心が16px以内に存在する時点数で、自動追跡精度ではない。今回の最大ピーク選択でも学習側64正解になったが、それとは別に位置違い2件がある。候補が増えたことだけで追跡品質の向上を確定しない。

これは追加学習した68時点自身への推論であり、過学習や同じ画角への適応を区別できない。未知試合の精度や、拡大入力による追加学習が通常画角での追加学習より優れることも示していない。

## 事前に固定した学習条件

元のTrackNetを初期値とし、既存と同じ960×540の固定9領域を512×288へ変換した。68時点それぞれ全9領域、計612入力を使用。人手中心を見て学習する領域を選び分ける処理はしていない。medianとBGR t−3..tも全て同じ変換を行った。

各入力の教師は、人手中心を座標変換したsigma3.5ネットワークpxのGaussian。中心を含まない領域は対象球中心のゼロマップで、球全般が物理的に存在しないという注釈ではない。中心を含む入力258、含まない入力354。観測不能9時点、プレー前後46時点、E/Fの26中心、旧A〜Dの52中心は学習に入れていない。

元のWBCELoss、Adam、学習率1e-4、batch2、seed20261109、勾配clip1を使用し、up_block_3とpredictorのみ更新。その他の重みと全BatchNormのrunning値を固定した。全3epoch・918更新の最終モデルだけを候補とし、途中のepochや別閾値を選ばない条件を学習前に保存した。推論閾値0.3、同じ固定9領域の最大ピーク選択を使用。旧画像特徴判定器は異なる応答分布で学習されたものなので、新モデルへそのまま使っていない。

元の全画面時系列出力がある時点は、その位置・有無・confidenceを保持する欠測補完として比較した。このため、既存出力の誤りを訂正する方式ではない。生の最大ピーク出力の結果も `training_summary.csv` に分けて保持した。

## 採否と次の課題

学習前の条件は、前段の59正解を全て保ち、正解数を59より増やし、位置違い0以下・観測不能時出力1以下を守ることだった。正解数の条件は満たすが、後ろの2条件に違反するため、評価側へ進めない。最終モデルのファイルは再現用に保存し、正規追跡の参照にはしない。閾値やepochのやり直しも行っていない。

この小規模試験で確認できたのは、画像側への適応で新たな中心候補を得られる例があることと、対象球を識別しきれず不要な出力も増えること。追加学習全般が無効という結論ではない。次の検討では、実球中心候補と誤位置候補を区別する材料・教師の多様性を、学習側で確保する必要がある。既知のE11に時系列条件を合わせ直す方針には戻さない。
