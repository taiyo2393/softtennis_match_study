## 操作

1. 動画を再生し、ラリーとしてプレーしている部分を確認する。
2. 動画の下の「まとめて仮設定」で開始・終了を指定する。「再生位置を開始に／終了に」も使える。冒頭ですでにプレー中なら開始を0秒にできる。
3. 範囲内をプレー中、範囲外をプレー前後に仮設定し、表を確認する。曖昧な時点は「判断できない」に変更する。時点ボタンでその位置の動画・元静止画へ移動できる。
4. 「この動画を保存して次へ」で保存する。8動画を一度に終える必要はない。

範囲指定は入力補助であり、厳密なサーブ接触やラリー終端の正解ではない。個別の対象時点を表で直せる。まだ区分を付けていない時点は保存を止め、不明なら不明として保存する。球の見え方を推測して位置をクリックする必要はない。
