## 固定したルール

基準にするのは、元の全画面・時系列方式の観測だけ。追加候補や手動中心を基準点に変換せず、順次保留した結果を次の判断へ伝播しない。

前後8ソースフレーム以内で、対象点の前後にある最も近い観測を1個ずつ使う。現行の出力を保留するには、この前後の組が必要である。追加候補では、片側にしか観測がない場合、その側の最も近い2観測を使える。ただし2観測は2ソースフレーム以上離れていることが必要。

2基準点どうしが整合し、対象点だけが両方と矛盾するときに限り、その出力を保留する。整合の境界は `16 + 32 × 経過ソースフレーム数` px。以前の16px許容幅と64px/2フレームの変位尺度を流用した探索的な値で、物理的な球速上限でも、今回の失敗3点から最適化した値でもない。

基準点どうしの動きも速い場合や、十分な基準点がない場合、映像切替をまたぐ場合は、矛盾を確定できないとして元の出力を保持する。保持されたことは実球と確認できたことを意味しない。方向転換やバウンドを含む場合に誤って正解を保留する危険も残る。単一の直線、コート内判定、移動距離だけを実球の定義にしていない。

この追加判断は最大8フレーム先の基準点を使い、その基準点を作る元の時系列方式も最大8フレーム先を参照する。合計最大16フレーム先（約0.267秒）と全クリップのmedianを使うオフライン処理で、リアルタイムの因果的な方式ではない。
