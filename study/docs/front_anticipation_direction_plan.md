# 前衛動作と実打球方向の時点別対応：予備研究計画

## 問いと対象

測定するのは、相手後衛のインパクト以前に観測された対象前衛の横方向動作が、インパクト後に確定した実打球方向とどの時点から対応するかである。意識的な予測、打球方向の読取り、または因果関係は主張しない。

対象前衛は固定主カメラの手前側前衛、打者は奥側後衛に限定する。インパクト時刻は人がフレームで確定する。連続した高精度ボール軌跡は研究の前提にしない。

## 変数

- `D`: 打球後に確定した実打球方向。対象前衛から見た `front_left` / `front_right`。
- `M(t)`: 時点 `t < 0` における対象前衛の横方向動作。現段階では高解像度人物検出枠の下辺中央の横座標を代理指標とし、過去だけを用いる短い窓で `left` / `right` / `stay` に離散化する。これは実際の足部キーポイントではないため、最終実証ではPose由来の足部座標との一致を監査する。
- `C(t)`: `M(t)` が方向を持ち、かつ `D` と一致するとき1。

`D` は打球後の結果を表す正解基準であり、打球前の前衛動作を作る入力には使わない。この分離により、方向ラベル確定に後続フレームを見ても、前衛動作の時間的先行性を壊さない。

## AIと人の役割

1. AIが固定主カメラ区間、対象前衛の高解像度追跡、打球後BallTrack候補列を作る。
2. 人がインパクトフレームを確定する。
3. AIがインパクト後0.017〜0.45秒のBallTrack候補から、連続性を満たす最長走行列だけを選び、画面上の左右方向を提案する。
4. 人が根拠動画で `D` を確認または修正する。候補不足・遮蔽・方向不明は `uncertain` として残す。

この試合の固定主カメラでは、人手監査により画面左/右と対象前衛から見た左/右が一致することを確認した。この対応はカメラ依存なので、各試合で目視確認し、崩れる画角は除外する。

## 時点別の報告

時点（例：-0.5, -0.3, -0.2, -0.1秒）ごとに、事前固定した移動判定閾値で以下を報告する。

1. 方向動作率 `P(M(t) != stay)`
2. 条件付き方向一致率 `P(M(t)=D | M(t) != stay)`
3. 全対象に対する一致率と、`stay`・`uncertain` の件数

`stay` を左右のどちらかに恣意的に割り当てると一致率が歪むため、必ず別に報告する。左右の基準率、混同行列、ブートストラップ信頼区間も併記する。

## 現時点で言える範囲

現在の10イベント・1試合は、半自動ラベル生成と前衛追跡がこの撮影条件で可能かを示す実現可能性の予備結果に限る。一般的な前衛行動や競技者の予測能力を結論にしてはならない。実証には複数試合・左右各50件程度を目標とし、評価は試合単位で分離する。
