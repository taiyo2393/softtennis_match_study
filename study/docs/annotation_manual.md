# アノテーション手引き

## インパクト

相手後衛のラケットとボールが接触したフレームを `impact_source_frame` とする。判定不能なら推測値を入れず、`exclusion_log.csv` に記録する。

## 対象前衛

対象は、相手後衛の打球時点でネット側に位置し、当該打球への動作を測定する選手とする。AIのtrack IDではなく、`target_front_player_id` で人物を一意に指定する。

## カット・リプレイ

解析窓の内部または安全マージン内に、カット、リプレイ、著しいズーム、遮蔽がある試技は主解析から除外する。

## 修正

AI出力を直接上書きしない。修正前後の値と理由を `annotations/corrections.csv` に残す。
