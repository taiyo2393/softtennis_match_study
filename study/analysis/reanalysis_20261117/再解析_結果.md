# match1 前衛の打球前の横移動と相手後衛の打球方向：統計的再解析

実行日と環境・入力SHA-256は `metadata.json` に記録。主解析は main80（80場面、320行）、感度解析は all98（98場面、392行）。各場面の -0.5/-0.3/-0.2/-0.1 秒を使用し、t = 0 秒は含めない。

## 結果の解釈

main80 の一致率は46.2–81.8%だった。4時点のHolm補正後の二項検定は算出可能な全時点で有意でなかった（有意水準5%）。4時点のHolm補正後のFisherの正確検定は算出可能な全時点で有意でなかった（有意水準5%）。AUCのMann–Whitney U検定の未補正p値は0.1076–0.5796だった。有意な結果でも、この1試合の探索的解析から一般的な関連が確認されたとは扱わない。有意でないことも、関連が存在しないことの証明ではない。

一致率は**判定ありの場面が分母の条件付きの値**であり、main80の判定率は13.8–25.0%だった。表Aで一致率が最も高い-0.2秒の81.8%は9/11で、全80場面のうち一致は9/80＝11.25%。一致率の95%CIは[48.2%, 97.7%]である。

## 方法と定義

`d = signed_displacement_toward_actual_court_width`。正の閾値では `abs(d) >= thr` を判定あり、そのうち `d > 0` を一致、`d < 0` を不一致とした。`abs(d) < thr` は判定なし（stay）。thr = 0のみ `d != 0` を判定ありとする。既存の方向ラベルを使って数え直すのではなく、記録されたdから再計算した。thr = 0.015 の指定された8組の（判定数, 一致数）はすべてassertで再現確認した。変位の単位はコート幅に対する割合。

前衛から見た右向き変位vは、実際がfront_rightならv=d、front_leftならv=−d。AUCは実際の方向が右の場面と左の場面を全組合せで比較し、P(v_right > v_left) + 0.5 P(同値) とした。AUC=0.5が方向による順位差のない基準。これは学習・交差検証を行った予測モデルの性能値ではない。

一致率の95%CIはClopper–Pearson法。二項検定はp=0.5を帰無仮説とする両側検定で、4時点の多重比較は**Holmで補正**した（main80とall98はcohortごとに別の検定族）。多数派基準は、同じ判定ありの場面で**いつも多い方を答える場合の参照値**である。全場面での多数派も別に示す。多数派は同じデータから得た記述的な参照値であり、その基準に対する有意差検定や汎化性能の評価はしていない。

前衛の動きと打球方向の関連を調べる偶然の水準は、**独立のときの期待一致率**であり、多数派基準とは区別する。判定ありの場面における右移動の割合をp_move_right、実際の右打球の割合をp_actual_rightとして、`p_move_right * p_actual_right + (1 - p_move_right) * (1 - p_actual_right)`を計算した。右移動は `v_front_right_court_width > 0`。移動方向（右・左）×実際の打球方向（右・左）の2×2表に両側Fisherの正確検定を適用し、二項検定とは別にcohortごとの4時点内でHolm補正した。行または列の和が0のときFisherのp値は未定義とする。

AUCとdの平均の95%CIは、後述の推定ラリーまとまりを等確率で復元抽出するクラスタ・ブートストラップ（10000回、seed=20261117）の2.5/97.5百分位点。各反復で元と同数のまとまりを抽出し、その全場面と重複を保持して、場面を単位としたAUC・平均を再計算した。両方向がそろわないAUC反復は除外し、その数をCSVに記録。AUCのp値は、同値補正・連続性補正を行う両側Mann–Whitney U検定（漸近法）。多重比較の補正はしていない。

**二項検定・Fisherの正確検定・Clopper–Pearson CI・Mann–Whitneyのp値は場面間の独立性を仮定する。Holm補正は同じラリー内の依存を補正しない。** クラスタ・ブートストラップで依存を考慮したのはDのAUCと平均のCIであり、Aのp値・CIをラリー単位で補正したものではない。DのCIも時点ごとの95%CIで、同時信頼区間ではない。

## 研究上の限界と発表で述べられる範囲

これは**1試合の観察**であり、前衛が打球方向を「予測した」ことや因果関係は示さない。時点、閾値、解析対象の選択を含む探索的な再解析で、事前登録された確認的研究ではない。左右方向の偏り、対戦組合せ、抽出条件、計測誤差などの影響を分離していない。閾値で判定ありを選ぶため、条件付き一致率を全場面の性能へ一般化できない。推定ラリーを用いたCIでも、1試合・少数選手から他試合や他選手への一般化はできない。

中間発表の補足としては、「80場面中、移動量の閾値0.015以上の場面は各時点11–20場面で、その一致率は46.2–81.8%だった。独立のときの期待一致率は49.7–52.1%である。4時点のHolm補正後の二項検定は算出可能な全時点で有意でなかった（有意水準5%）。4時点のHolm補正後のFisherの正確検定は算出可能な全時点で有意でなかった（有意水準5%）。AUCのMann–Whitney U検定の未補正p値は0.1076–0.5796だった。これは1試合の探索的な結果であり、予測性能や一般的な関連の確認を意味しない」と述べる。
